# T-1：解码降到 Op

> **现状**：默认 `rv32-classify` 为 `decode` → `lower` → T0–T5。本文件描述「字节 → 带索引的 `Op` 表」；不再使用 Isla footprint / summary。

`lower`（原 T-1）用 `riscv_isa` 解码 RV32IMC，在 `Environment` 下解析调用目标与布局，产出 `Op` 序列。表面字符串由 `Op::text` 按 bpftool 就地写法生成（`wN`、`if … goto +0xN`、`*(u32 *)(…)`）。

## 例子

```text
0: w2 += -0x10
1: *(u32 *)(w2 + 0xc) = w1
5: w9 = *(u32 *)(w10 + 0x0)
9: if w11 < w12 goto +0xa
```

未知编码、越界目标、合同与字节不一致时拒绝，不猜测。
