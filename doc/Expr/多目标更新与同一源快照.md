# 多目标更新与同一源快照

一次局部效果可以写多个对象。所有右侧必须先从同一个执行前关系集合取得，再一次性应用更新。

设实际目标为互异的 \(r_1,\ldots,r_m\)，所需旧源项为 \(t_1,\ldots,t_n\)。构造

\[
E_i=\{r_j=f_j^\star(t_1,\ldots,t_n):1\le j\le m\},
\qquad E_g'=E_g\times E_i.
\]

某个 \(f_j\) 只使用其中实际所需的源，不因此增加其他输入要求。目标可以同时包含真实寄存器和虚拟单元；即使真实源同时也是写回目标，其旧项也在更新前固定。顺序计算并立即覆写某个目标，会改变其他输出的取源，不能替代本规则。

FETCH、XCHG、CMPXCHG 的具体公式与旧值返回证明见[原子数值更新与旧值返回](原子数值更新与旧值返回.md)。包存储的多字节写入见[包字节读写](包字节读写.md)，辅助调用的返回赋值和 Map 关系见[辅助调用结果](辅助调用结果.md)。本文只维护它们共同的取源和应用顺序。

局部目标互异不代替右侧的类型检查或访问条件。键唯一性的整体结论见[局部值效果的类型与解释保持](局部值效果的类型与解释保持.md)，覆盖操作本身见[关系集合按键覆写](关系集合按键覆写.md)。
