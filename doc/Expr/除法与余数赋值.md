# 除法与余数赋值

本规则用一个运算宽度 q 统一除法和余数。\(A,B\in\mathbb B_q\)，令 \(x=s_q(A)\)、\(y=s_q(B)\)。向零商 TQ、余数 TR 见[共同数值函数](位向量与共同数值函数.md#向零商与余数)。

以 d 表示除零时的商，定义

\[
\mathrm{UDIV}_{q,d}(A,B)=
\begin{cases}d&B=0,\\\lfloor A/B\rfloor&B\ne0,\end{cases}
\qquad
\mathrm{UREM}_q(A,B)=
\begin{cases}A&B=0,\\A-B\lfloor A/B\rfloor&B\ne0.\end{cases}
\]

\[
\mathrm{SDIV}_{q,d}(A,B)=
\begin{cases}
d&y=0,\\
2^{q-1}&x=-2^{q-1}\land y=-1,\\
M_q(\mathrm{TQ}(x,y))&\text{其他情况},
\end{cases}
\]

\[
\mathrm{SREM}_q(A,B)=
\begin{cases}
A&y=0,\\
0&x=-2^{q-1}\land y=-1,\\
M_q(\mathrm{TR}(x,y))&\text{其他情况}.
\end{cases}
\]

**行为差异。** RV32 取 q=32、\(d=2^{32}-1\)；DIVU、REMU、DIV、REM 分别采用 UDIV、UREM、SDIV、SREM。eBPF 取 q=32 或 64、d=0；DIV、MOD、SDIV、SMOD 分别采用这四个函数。余数的除零与有符号溢出规则相同；商的除零结果不同。

对宽度 v 的实际源解释 a、b，使用 \(A=M_q(a)\)、\(B=M_q(b)\)，将 q 位结果作为同一非负整数放入 \(\mathbb B_v\)。符号输出为 \(\{r_d=f_i^\star(t_a,t_b)\}\)。RV32 取 v=32、源为 rs1/rs2；eBPF 取 v=64、源为目标旧值和寄存器或立即数源，取源见[算术与位运算赋值](算术与位运算赋值.md)。

上述特殊输入有确定结果，不因除零或最小负数除以 −1 拒绝。符号项能否求值仍由[部分求值](符号项求值与常量折叠.md)决定，数值函数有定义不保证任意符号应用可求值。

数值依据为 [M 扩展](https://docs.riscv.org/reference/isa/v20260120/unpriv/m-st-ext.html)和 [BPF ISA](https://docs.kernel.org/bpf/standardization/instruction-set.html)。
