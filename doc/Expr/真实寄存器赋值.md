# 真实寄存器赋值

真实目标使用[寄存器定义](../寄存器定义.md)给出的身份和位宽。每个实际赋值产生完整等式 \(r_d=t'_d\)，右侧与目标位宽匹配；数值函数按[局部效果前提](指令局部效果的前提.md)选择。

RV32 使用 Real32；eBPF 使用 Real64，ALU32 仍写同一个 Real64 身份，其低位视图和写回见[低位视图与写回](真实寄存器低位视图与写回.md)。

## 固定与只读目标

RV32 读取 x0 恒得 \(C_{32}(0)\)，合法写入 x0 不生成赋值。若输入含 \(x_0=t\)，要求 \(\operatorname{solve}_{32}(t)=C_{32}(0)\)，否则规则无定义。结果被丢弃不免除访问、取源或控制前提。

eBPF 的 r10 是只读帧指针，写入它不属于成功规则。虚拟栈写入的目标身份与真实 r10 不同。

**命题（固定与只读值保持）。** 对合法输入，成功更新保持 x0 的固定零值和已定义的 r10 值。

**证明。** 成功规则不产生这两个目标的覆写键，原有等式得以保留。若未显式记录 x0 等式，其读取规则仍返回零。虚拟资源目标与 Real 身份类别不同，不能覆盖这些键。\(\square\)

## 值赋值与资源身份

真实赋值不直接生成虚拟资源内容等式。修改 SP、移动包或 Map 地址、指针加减都只按其实际目标写入 Real；资源来源的传播另需绑定语义。

按问题选择[常元](常元赋值.md)、[移动与符号扩展](移动与符号扩展赋值.md)、[算术与位运算](算术与位运算赋值.md)、[乘法高半](乘法高半赋值.md)、[除法与余数](除法与余数赋值.md)、[字节序转换](字节序转换赋值.md)、[资源读取与位置赋值](资源读取与位置赋值.md)或[链接值赋值](跳转链接值赋值.md)。这些规则通过链接使用，不在本文重复公式。

身份与限制依据为 [RV32I 寄存器模型](https://docs.riscv.org/reference/isa/v20260120/unpriv/rv32.html)与 [BPF ABI](https://www.kernel.org/doc/html/latest/bpf/standardization/abi.html)。
