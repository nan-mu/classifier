# 局部值效果的类型与解释保持

本命题验证已定义数值规则与符号表示的内部一致性。输入键唯一、源项类型正确且齐备、指令参数合法、资源绑定唯一且访问有效，均作为前提。数值运算的解释必须遵循所给签名；未解释外部结果不套用纯数值全函数假设。

**命题。** 对成功的局部效果 \(E_i\)：

1. \(E_i\) 是有限 Expr 集合，每个关系左右两侧位宽一致。
2. 对任一类型正确、完整应用项属于纯数值子域的规则，在其解释域内有

\[
\left[\!\left[f_i^\star(t_1,\ldots,t_n)\right]\!\right]_{\nu,\theta}
=\widehat f_i(\left[\!\left[t_1\right]\!\right]_{\nu,\theta},\ldots,
\left[\!\left[t_n\right]\!\right]_{\nu,\theta}).
\]

3. 局部关系键唯一，整体按键覆写保持键唯一。

**证明。** 算术、常元、链接与读取规则产生匹配真实目标宽度的项。32 位运算写 Real64 时明确零扩展；虚拟单元写入由[字段覆盖性质](单元字段读写.md#字段覆盖性质)保持目标宽度；[包字节规则](包字节读写.md)同时满足 32 位项和字节值域；原子数值结果按单元宽度取模。普通规则写一个目标，包写入写有限个不同字节，原子多目标分别写虚拟与真实身份，故目标有限且键互异。

符号提升是应用项的 solve。由[纯数值子域的解释保持性](符号项求值与常量折叠.md#纯数值子域的解释保持性)，solve 不改变应用项的解释，再用应用项定义得到第二项。最后应用[按键覆写性质](关系集合按键覆写.md)。\(\square\)

第二项的纯数值前提约束整个应用项，包括其全部子项。若源项含外部事件或包字节等未解释运算，固定解释补全仍可定义数值运算的解释，但上述纯数值 solve 命题不能直接证明其保持性；这需要另外的部分求值保持性论证。

固定与只读寄存器的保持见[真实寄存器赋值](真实寄存器赋值.md)；高位清零、字段覆盖、旧值返回的证明分别放在其主题正文中。资源绑定正确、完整调用与访问观察、并发语义及跨架构行为等价仍需独立论证。本文不将数学推导视为 ISA 语义正确性的完整证明或已有 Lean 形式化证明。
