# 移动与符号扩展赋值

移动只读取指定源，不要求目标旧值；固定与只读目标采用[真实寄存器赋值](真实寄存器赋值.md)的规则。符号提升采用[求值规则](符号项求值与常量折叠.md)。

源项为 \(t_s\in\mathrm{Term}_v\)，运算宽度 \(q\le v\)。移动采用 \(\widehat f(a)=M_q(a)\)，输出 \(\{r_d=f^\star(t_s)\}\)。RV32 C.MV 取 q=v=32，函数为恒等；eBPF MOV 寄存器源取 v=64、q=32 或 64。

eBPF MOVSX 的源位宽为 \(\ell\)，定义

\[
\widehat f(a)=M_q(s_\ell(M_\ell(a))),
\qquad E_i=\{r_d=f^\star(t_s)\}.
\]

q=32 时 \(\ell\in\{8,16\}\)，q=64 时 \(\ell\in\{8,16,32\}\)。32 位形式先符号扩展至 32 位，再将该非负模式写入完整 64 位真实寄存器，其高 32 位为零。

立即数移动采用[常元赋值](常元赋值.md)的构造。

数值依据为 [RV32I](https://docs.riscv.org/reference/isa/v20260120/unpriv/rv32.html)、[C 扩展](https://docs.riscv.org/reference/isa/v20260120/unpriv/c-st-ext.html)及 [BPF ISA](https://docs.kernel.org/bpf/standardization/instruction-set.html)。
