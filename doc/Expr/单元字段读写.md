# 单元字段读写

本文定义一个规范单元内的读取与覆盖函数。访问对象及字段位置须由[资源绑定](指令局部效果的前提.md)确定；Stack 与 Map 共用这些数值函数。

设访问位宽为 \(q\)，单元位宽为 \(w\)，字段最低有效位位置为 \(\ell\)，满足 \(0\le\ell\)、\(\ell+q\le w\)。\(\Gamma\) 根据字节偏移与字节序确定 \(\ell\)。例如单元内字节偏移 d，在 LE 下为 \(\ell=8d\)，在 BE 下为 \(\ell=w-q-8d\)。

定义字段投影

\[
P_{\ell,q}^{(w)}(a)
=M_q\!\left(\left\lfloor a/2^\ell\right\rfloor\right).
\]

若旧单元等式为 \(r_v=t_v\)，读取到机器宽度 \(v\) 的目标，使用数值函数

\[
\widehat R_Z(a)=Z_{q\to v}^{(w)}(P_{\ell,q}^{(w)}(a)),
\qquad
\widehat R_S(a)=S_{q\to v}^{(w)}(P_{\ell,q}^{(w)}(a)),
\]

并输出 \(\{r_d=R_Z^\star(t_v)\}\) 或 \(\{r_d=R_S^\star(t_v)\}\)。RV32 按 LB/LH 或 LBU/LHU/LW 选择；eBPF 按 MEMSX 或 MEM 选择。要求 \(q\le\min(w,v)\)。

设源值 \(b\in\mathbb B_v\)，且 \(q\le v\)。字段写入函数为

\[
U_{\ell,q}^{(w,v)}(a,b)
=a-2^\ell P_{\ell,q}^{(w)}(a)+2^\ell M_q(b),
\qquad
E_i=\{r_v=U_{\ell,q}^{(w,v),\star}(t_v,t_s)\}.
\]

完整写入 \((\ell,q)=(0,w)\) 时，结果为 \(M_w(b)\)，不需要目标旧值；应采用只含源项的函数。部分写入则需要完整旧值。新等式覆写完整单元，而非仅增加低位约束。

这覆盖 RV32 的 SB/SH/SW、C.SW/C.SWSP，以及 eBPF 的 ST/STX 普通写入。eBPF ST 的立即数先按其符号扩展规则构造源项。跨规范单元访问必须另外给出唯一的分段绑定与组合规则；不能将其默认为单个单元的低位写入。

## 字段覆盖性质

**引理 M2（Stack/Map 字段覆盖）。** \(a'=U_{\ell,q}^{(w,v)}(a,b)\) 属于 \(\mathbb B_w\)，目标字段为 \(M_q(b)\)，字段外各位保持旧值。

**证明。** 唯一分解为 \(a=h2^{\ell+q}+c2^\ell+d\)，其中 \(c\in\mathbb B_q\)、\(0\le d<2^\ell\)。U 将 c 替换为 \(M_q(b)\)，保留 h、d。新各段宽度不变，故仍属于 \(\mathbb B_w\)。\(\ell=0\) 时取 d=0。\(\square\)

## 同位宽传值

若虚拟单元 \(r_v\in\mathrm{Reg}_w\) 已有完整等式 \(r_v=t\)，读取该单元到真实寄存器 \(r_d\) 的局部关系为 \(r_d=t\)。反向写入则使用源真实寄存器的旧项，产生 \(r_v=t_s\)。

目标必须是实际绑定的一个单元，且源值满足目标类别的值域约束。不同类别标记不因公式相同而成为同一目标；源项也不是对随后可变寄存器的引用。Stack/Map 字段访问采用本文函数，Packet 访问采用[包字节读写](包字节读写.md)规则，不能将整个宽值直接赋给一个包字节。

## 访问参数与源项

RV32 的 SB、SH、SW 分别写 8、16、32 位，C.SW、C.SWSP 写 32 位，真实源项宽度为 32。完整覆盖只可能发生在 q=w=32；写 SR 或 Map64 的 32 位字段仍须保留字段外旧位。

eBPF 普通 ST、STX、STORE_REL 可写 8、16、32、64 位，真实源项宽度为 64。ST 由[立即数规则](常元赋值.md)取得源项；STX、STORE_REL 读取实际源寄存器的完整等式。STORE_REL 使用相同数值覆盖函数，未定义 release 或原子观察。

低位写入是上述 U 函数的 \(\ell=0\) 情形。若 32 位单元旧值为 \(\mathtt{0x10000}\)，16 位写入 1 后为 \(\mathtt{0x10001}\)。由字段覆盖引理，旧高位保持；[真实 ALU32 写回](真实寄存器低位视图与写回.md)则将完整目标高位清零。两种规则的写入范围不同。

Stack 与 Map 的数值函数相同，只改变唯一绑定给出的目标类别。绑定、资源有效性、访问观察及跨单元一致性仍需独立论证。数值依据为 [RV32I](https://docs.riscv.org/reference/isa/v20260120/unpriv/rv32.html)、[BPF ISA](https://docs.kernel.org/bpf/standardization/instruction-set.html)及 [LLVM 扩展定义](https://llvm.googlesource.com/llvm-project/+/17bfc00f7c4a424d7b5dc6da575865833701fd1a%5E%21/)。
