# 左值

左值指定关系所描述的寄存器对象；对象的完整定义见[寄存器定义](../寄存器定义.md)。

## 左值的类型

对位宽 \(w\in\{32,64\}\)，Expr 的左值是 \(r_w\in\mathrm{Reg}_w\)，不是地址项，也不是一个待求值的 Term。左值与右值必须同位宽。

Real、Stack、Map、Packet 均可作为左值。类别、位宽和标识共同决定对象身份；相同数值不使两个对象相等。

## 左值与写入对象

完整等式 \(r_w=t_w\) 可以给出对象的完整值。低位等式或不等式只给出约束，不能自动作为完整源值。关系的含义见[关系符](关系符定义.md)。

LOAD 读取虚拟对象并以真实目标为左值；普通 STORE 以所写虚拟对象为左值。基址寄存器不会仅因参与寻址而成为写入对象。访问对象须由[资源绑定](指令局部效果的前提.md)确定。

指向同一资源单元的别名采用同一左值标记。改变访问宽度不重新建立独立对象；Stack/Map 使用规范单元，Packet 使用规范字节。

值绑定以寄存器为键；新赋值清除该左值的旧绑定与全部比较约束。约束按完整 Expr 结构去重，见[严格覆写](关系集合按键覆写.md)。
