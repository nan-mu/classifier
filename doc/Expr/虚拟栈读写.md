# 虚拟栈读写

本文只讨论已绑定栈对象如何参与读写关系。规范单元的字段函数见[字段读写](单元字段读写.md)。

栈访问必须由绑定确定栈资源及其规范单元，而不是按当前源寄存器名称分类。RV32 中以 SP 或其已知别名寻址的 LOAD/STORE，eBPF 中以 \(r_{10}\) 或其已知别名寻址的 LDX/ST/STX，都可以归入 Stack；前提是访问来源确实已绑定为栈。

入口契约也可将固定上下文字段绑定为 Stack 类别的单元，采用同一分类规则。该归类由入口模型规定，不是 ISA 从地址数值推导出的类别。

可将标识写为 \(\alpha=(\phi,u)\)，其中 \(\phi\) 区分栈资源，\(u\) 区分规范单元。调整 SP 后，访问同一栈单元仍使用同一标记。合法压缩栈读写使用普通字访问的值规则。

LOAD 从 Stack 取值，只写真实目标。普通 STORE 向 Stack 写值，只写 SW/SR；作为基址或数据源的真实寄存器不因普通 STORE 被改写。

同时写回旧值的特殊访问采用[原子数值更新与旧值返回](原子数值更新与旧值返回.md)，其多目标效果不归入上述普通 STORE。
