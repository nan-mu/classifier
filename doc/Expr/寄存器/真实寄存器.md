# 真实寄存器

## 真实寄存器赋值

真实目标使用[寄存器定义](../../寄存器定义.md)给出的身份和位宽。每个实际赋值产生完整等式 \(r_d=t'_d\)，右侧与目标位宽匹配。

## 固定与只读目标

### RV32（真实寄存器赋值）

RV32 使用 Real32。

RV32 读取 x0 恒得 \(C_{32}(0)\)，合法写入 x0 不生成赋值。若输入含 \(x_0=t\)，要求 \(\operatorname{solve}_{32}(t)=C_{32}(0)\)，否则规则无定义。结果被丢弃不免除访问、取源或控制前提。

### eBPF（真实寄存器赋值）

eBPF 使用 Real64，ALU32 仍写同一个 Real64 身份，其低位视图和写回见[真实寄存器低位视图与写回](#真实寄存器低位视图与写回)。

eBPF 的 r10 是只读帧指针，写入它不属于成功规则。虚拟栈写入的目标身份与真实 r10 不同。

## 固定与只读值保持

**命题（固定与只读值保持）。** 对合法输入，成功更新保持 x0 的固定零值和已定义的 r10 值。

**证明。** 成功规则不产生这两个目标的覆写键，原有等式得以保留。若未显式记录 x0 等式，其读取规则仍返回零。虚拟资源目标与 Real 身份类别不同，不能覆盖这些键。\(\square\)

## 值赋值与资源内容

真实赋值不直接生成虚拟资源内容等式。修改 SP、移动包或 Map 地址、指针加减都只按其实际目标写入 Real；所得地址项与所指资源的联系须由相应访问规则确定。

RV32 的身份与限制依据为 [RV32I 寄存器模型](https://docs.riscv.org/reference/isa/v20260120/unpriv/rv32.html)。eBPF 的身份与限制依据为 [BPF ABI](https://www.kernel.org/doc/html/latest/bpf/standardization/abi.html)。

## 真实寄存器低位视图与写回

真实寄存器身份由[寄存器定义](../../寄存器定义.md)给定。低位视图不引入另一寄存器身份；写回宽度与运算宽度分别确定。

### eBPF（真实寄存器低位视图与写回）

eBPF 的 \(w_j\) 表示 Real64 \(r_j\) 的低 32 位视图，源项 \(t_j\) 为执行前完整等式 \(r_j=t_j\) 的右侧项。低位源项为 \(\mathrm{LOW}_{32}^{(64),\star}(t_j)\)，其中 \(\mathrm{LOW}_{32}^{(64),\star}\) 为低 32 位投影的符号提升。

普通 ALU32（ADD、SUB、MUL、DIV、MOD、SDIV、SMOD、AND、OR、XOR、LSH、RSH、ARSH、NEG）、运算宽度 \(q=32\) 的 MOV 与 MOVSX（MOVSX 的源位宽 \(\ell\in\{8,16\}\)）的结果 \(t_{32}\in\mathrm{Term}_{32}\) 写回完整 Real64 \(r_j\)，\(Z_{32\to64}^{(32),\star}\) 为 32 到 64 位零扩展的符号提升：

\[
r_j=Z_{32\to64}^{(32),\star}(t_{32}).
\]

旧值为 \(\mathtt{0x10000}\) 或 \(\mathtt{0x100000000}\)，32 位赋值 1 后都得到 \(r_j=C_{64}(1)\)。虚拟单元局部写入采用[单元字段读写](单元字段读写.md#单元字段读写)的保留字段外位规则，不能套用这个真实写回规则。

**命题（高位清零）。** 普通 32 位算术、移动与符号扩展写回的真实值 \(y\) 满足 \(0\le y<2^{32}\)，高 32 位为零。

**证明。** 这些运算最终取 \(M_{32}\)，或给出 \(\mathbb B_{32}\) 内的非负值。负数符号扩展也先产生其 32 位非负模式；零扩展保留该模式并清零高位，不依赖目标旧高位。\(\square\)

END 即使属于 ALU 指令类，也允许 64 位转换，不受上述结论覆盖，见[字节序转换赋值](#字节序转换赋值)。

### RV32（真实寄存器低位视图与写回）

RV32 的真实目标本身为 32 位，不需要同类 64 位写回规则。
## 常元赋值

共同取源与失败条件见[指令结果的前提](../Expr.md#指令结果的前提)。目标合法性及固定、只读寄存器处理见[真实寄存器赋值](#真实寄存器赋值)。立即数与槽位参数须满足[规则合法域](../../NodeInference/step.md#局部规则的合法域)。

常元赋值不读取目标旧值。给定完整常元 \(c\in\mathbb B_v\)，局部关系为 \(\bar{E}_i=\{r_d=C_v(c)\}\)。

### 架构对应（常元赋值）

#### RV32（常元赋值）

RV32 LUI 使用满足 \(M_{12}(U)=0\) 的 \(U\in\mathbb B_{32}\)。C.LI 使用 \(M_{32}(\iota)\)；C.LUI 使用 \(M_{32}(s_6(h)\cdot 2^{12})\)，其中 \(h\in\mathbb B_6\) 是该指令六位立即数字段的值；该字段值是否合法由 [step 的局部规则合法域](../../NodeInference/step.md#局部规则的合法域)决定。

#### eBPF（常元赋值）

eBPF 的 32 位立即数模式 \(\iota\) 形成源项 \(t_{\mathrm{imm}}=C_{64}(M_{64}(s_{32}(\iota)))\)。MOV 立即数按运算宽度 q 写回 \(C_{64}(M_q(s_{32}(\iota)))\)。

普通 LDDW 的配对槽位提供 \(\iota_0,\iota_1\in\mathbb B_{32}\)，完整常元为 \(C_{64}(\iota_0+2^{32}\iota_1)\)。其他 LDDW 子类型不由这个常元公式确定，见[资源读取与位置赋值](资源读取与位置赋值.md#资源读取与位置赋值)。

### 参数与数值依据

[指令参数与规则定义域](../../NodeInference/step.md#局部规则的合法域)。

数值依据为 [RV32I](https://docs.riscv.org/reference/isa/v20260120/unpriv/rv32.html)。
压缩指令的数值依据为 [C 扩展](https://docs.riscv.org/reference/isa/v20260120/unpriv/c-st-ext.html)。
eBPF 的数值依据为 [BPF ISA](https://docs.kernel.org/bpf/standardization/instruction-set.html)。

## 移动与符号扩展赋值

移动只读取指定源，不要求目标旧值。

源项为 \(t_s\in\mathrm{Term}_v\)，运算宽度 \(q\le v\)。移动采用 \(\widehat f(a)=M_q(a)\)，输出 \(\{r_d=f^\star(t_s)\}\)。立即数移动采用[常元赋值](#常元赋值)的构造。

### 架构对应（移动与符号扩展赋值）

#### RV32（移动与符号扩展赋值）

RV32 C.MV 取 q=v=32，函数为恒等。

#### eBPF（移动与符号扩展赋值）

eBPF MOV 寄存器源取 v=64、q=32 或 64。

eBPF MOVSX 的源位宽为 \(\ell\)。\(\widehat f\) 为数值函数，\(f^\star\) 为其[符号提升](../Term/solve.md#solve-的化简与求值)，\(\bar{E}_i\) 为写入真实目标 \(r_d\) 的局部关系：

\[
\widehat f(a)=M_q(s_\ell(M_\ell(a))),
\qquad \bar{E}_i=\{r_d=f^\star(t_s)\}.
\]

q=32 时 \(\ell\in\{8,16\}\)，q=64 时 \(\ell\in\{8,16,32\}\)。32 位结果的完整写回见[真实寄存器低位视图与写回](#真实寄存器低位视图与写回)。

### 数值依据

RV32 的数值依据为 [RV32I](https://docs.riscv.org/reference/isa/v20260120/unpriv/rv32.html)。压缩形式的数值依据为 [C 扩展](https://docs.riscv.org/reference/isa/v20260120/unpriv/c-st-ext.html)。eBPF 的数值依据为 [BPF ISA](https://docs.kernel.org/bpf/standardization/instruction-set.html)。

## 算术与位运算赋值

数值函数见[位向量与共同数值函数](../Term/数值函数.md#共同数值函数)，符号提升与部分求值见[solve 的化简与求值](../Term/solve.md#solve-的化简与求值)。指令参数的[合法域](../../NodeInference/step.md#局部规则的合法域)。

设运算宽度为 \(q\in\{32,64\}\)，源项承载宽度为 \(v\)，满足 \(q\le v\)。\(G_q\) 为共同二元数值函数，\(\widehat f_{G,q,v}\) 将 v 位输入 a、b 的低 q 位送入 \(G_q\)：

\[
\widehat f_{G,q,v}(a,b)=G_q(M_q(a),M_q(b)),
\qquad f_{G,q,v}:\mathbb B_v^2\to\mathbb B_v.
\]

结果作为同一非负整数放入 \(\mathbb B_v\)。\(t_a,t_b\in\mathrm{Term}_v\) 为两源项，\(r_d\) 为真实目标，\(\bar{E}_i\) 为局部关系：

\[
\bar{E}_i=\{r_d=f_{G,q,v}^{\star}(t_a,t_b)\}.
\]

共同运算为 ADD、SUB、MULLO、AND、OR、XOR、SHL、LSHR、ASHR。移位量与算术右移的取整规则见[移位](../Term/数值函数.md#移位)。右侧取源顺序见[多目标更新与同一来源](../Expr.md#多目标更新与同一来源)。

RV32 的数值依据为 [RV32I](https://docs.riscv.org/reference/isa/v20260120/unpriv/rv32.html)。乘法的数值依据为 [M 扩展](https://docs.riscv.org/reference/isa/v20260120/unpriv/m-st-ext.html)。压缩形式的数值依据为 [C 扩展](https://docs.riscv.org/reference/isa/v20260120/unpriv/c-st-ext.html)。eBPF 的数值依据为 [BPF ISA](https://docs.kernel.org/bpf/standardization/instruction-set.html)。

### 源项与助记符的对应

#### RV32 的源项与助记符

RV32 取 \(q=v=32\)。普通双源指令读取 rs1、rs2，不默认读取 rd 的旧值。MUL 使用 MULLO；SLL、SRL、SRA 分别使用 SHL、LSHR、ASHR。SLT、SLTU 使用共同的 LTS、LTU，写回 0 或 1；这些结果是 Expression。

立即数形式将 \(I=M_{32}(\iota)\) 固定在函数内，只读取一个寄存器源。ADDI、ANDI、ORI、XORI 分别使用 ADD、AND、OR、XOR；SLTI、SLTIU 使用 LTS、LTU。SLTIU 的立即数采用符号扩展后的无符号模式比较。SLLI、SRLI、SRAI 固定合法的 \(0\le k<32\)。相应输出为 \(\{r_d=f_i^\star(t_a)\}\)。

#### eBPF 的源项与助记符

eBPF 取 \(v=64\)，运算宽度 q 为 32 或 64。二元运算读取目标旧项 \(t_d\) 和源项 \(t_{\mathrm{src}}\)，输出使用上式的 \(t_a=t_d\)。寄存器源提供已有完整等式的右侧；立即数源采用[常元赋值](#常元赋值)的立即数项。MUL、LSH、RSH、ARSH 分别对应 MULLO、SHL、LSHR、ASHR。q=32 的结果作为 64 位值写回，见[真实寄存器低位视图与写回](#真实寄存器低位视图与写回)。

### 采用相同函数的压缩形式

#### RV32 的压缩形式

合法、非 HINT 的压缩形式使用上述 32 位函数：

- C.ADDI4SPN 读取 x2 并写指定目标；C.ADDI 读取并写同一目标；C.ADDI16SP 读取并写 x2。三者使用固定立即数的 ADD。
- C.SRLI、C.SRAI、C.SLLI、C.ANDI 读取并写同一目标，分别使用固定参数的 LSHR、ASHR、SHL、AND。
- C.SUB、C.XOR、C.OR、C.AND、C.ADD 读取目标旧项和另一源项，分别使用 SUB、XOR、OR、AND、ADD，并写回该目标。

C.MV 见[移动与符号扩展赋值](#移动与符号扩展赋值)。C.LI、C.LUI 见[常元赋值](#常元赋值)。C.ADDI16SP 修改真实 x2；C.ADDI4SPN 只计算真实目标。两者都不自动新增或写入虚拟栈单元。

### 一元取负与当前位置加常元

#### eBPF 的一元取负

NEG 是一元取负，读取目标旧项 \(t_d\)，使用 \(\widehat f(a)=\mathrm{NEG}_q(M_q(a))\)，输出 \(\{r_d=f^\star(t_d)\}\)。eBPF 仍取 v=64。

#### RV32 的当前位置加常元

AUIPC 的 U 采用[常元赋值](#常元赋值)中 LUI 的同一个上位常元。AUIPC 使用 \(\widehat f(\pi)=\mathrm{ADD}_{32}(\pi,U)\)，输出 \(\{r_d=f^\star(t_\pi)\}\)。\(t_\pi\) 必须描述当前指令的机器地址，不能沿用上一次位置项；位置身份与绑定见[指令序列与程序位置](../../NodeInference/路径.md)。

## 乘法高半赋值

乘法低半采用[共同 MULLO 函数](../Term/数值函数.md#算术)。参数顺序和有符号解释由指令确定。失败处理见[检查源项与访问对象](../../NodeInference/step.md#检查源项与访问对象)。

### RV32 乘法高半

RV32 的 rs1、rs2 提供旧源项 \(t_a,t_b\in\mathrm{Term}_{32}\)。\(a,b\in\mathbb B_{32}\) 为源项的数值，HU、H、HSU 分别表示无符号、双有符号与第一源有符号的高半函数，三个函数的签名均为 \(\mathbb B_{32}^2\to\mathbb B_{32}\)：

\[
\begin{aligned}
\widehat f_{\mathrm{HU}}(a,b)&=M_{32}(\lfloor ab/2^{32}\rfloor),\\
\widehat f_{\mathrm{H}}(a,b)&=M_{32}(\lfloor s_{32}(a)s_{32}(b)/2^{32}\rfloor),\\
\widehat f_{\mathrm{HSU}}(a,b)&=M_{32}(\lfloor s_{32}(a)b/2^{32}\rfloor).
\end{aligned}
\]

MULHU、MULH、MULHSU 分别采用上述函数，局部关系为 \(\bar{E}_i=\{r_d=f_i^\star(t_a,t_b)\}\)。MULHSU 的第一源有符号、第二源无符号，不能交换。高半计算使用向下取整，再取 32 位模式；其数学中间乘积不增加 64 位真实寄存器身份。

数值依据为 [M 扩展](https://docs.riscv.org/reference/isa/v20260120/unpriv/m-st-ext.html)。

## 除法与余数赋值

设运算宽度为 q，\(A,B\in\mathbb B_q\)，令 \(x=s_q(A)\)、\(y=s_q(B)\)。向零商 TQ、余数 TR 见[向零商与余数](../Term/数值函数.md#向零商与余数)。

\(d\in\mathbb B_q\) 表示除零时的商，UDIV、UREM 分别为无符号商、余数函数：

\[
\mathrm{UDIV}_{q,d}(A,B)=
\begin{cases}d&B=0,\\\lfloor A/B\rfloor&B\ne0,\end{cases}
\qquad
\mathrm{UREM}_q(A,B)=
\begin{cases}A&B=0,\\A-B\lfloor A/B\rfloor&B\ne0.\end{cases}
\]

SDIV 是 q 位有符号商函数；x、y 为 A、B 的有符号解释，d 为除零结果：

\[
\mathrm{SDIV}_{q,d}(A,B)=
\begin{cases}
d&y=0,\\
2^{q-1}&x=-2^{q-1}\land y=-1,\\
M_q(\mathrm{TQ}(x,y))&y\ne0\land\neg(x=-2^{q-1}\land y=-1),
\end{cases}
\]

SREM 是 q 位有符号余数函数；TR 取向零商对应的余数，\(M_q\) 将其化为 q 位非负模式：

\[
\mathrm{SREM}_q(A,B)=
\begin{cases}
A&y=0,\\
0&x=-2^{q-1}\land y=-1,\\
M_q(\mathrm{TR}(x,y))&y\ne0\land\neg(x=-2^{q-1}\land y=-1).
\end{cases}
\]

**行为差异。** 余数的除零与有符号溢出规则相同；商的除零结果不同。

对宽度 v 的实际源解释 a、b，使用 \(A=M_q(a)\)、\(B=M_q(b)\)，将 q 位结果作为同一非负整数放入 \(\mathbb B_v\)。符号输出为 \(\{r_d=f_i^\star(t_a,t_b)\}\)。立即数源按对应架构的取源规则构造。

上述特殊输入有确定结果，不因除零或最小负数除以 −1 拒绝。符号项能否求值仍由[部分求值](../Term/solve.md#部分求值与未解释运算)决定，数值函数有定义不保证任意符号应用可求值。

数值依据为 [M 扩展](https://docs.riscv.org/reference/isa/v20260120/unpriv/m-st-ext.html)和 [BPF ISA](https://docs.kernel.org/bpf/standardization/instruction-set.html)。

### 架构对应（除法与余数赋值）

#### RV32 除法与余数赋值

RV32 取 q=v=32、\(d=2^{32}-1\)，源为 rs1/rs2。DIVU、REMU、DIV、REM 分别采用 UDIV、UREM、SDIV、SREM。

#### eBPF 除法与余数赋值

eBPF 取 q=32 或 64、d=0；DIV、MOD、SDIV、SMOD 分别采用这四个函数。

eBPF 取 v=64，源为目标旧值和寄存器或立即数源，取源见[算术与位运算赋值](#算术与位运算赋值)。

## 字节序转换赋值

字节反转的数值公式见[字节反转](../Term/数值函数.md#字节反转)。

### eBPF（字节序转换赋值）

eBPF END、BSWAP 使用转换宽度 \(q\in\{16,32,64\}\)。D 为 END 指定的 LE 或 BE，H 为模型的固定字节序。目标旧项为 \(t_d\)，\(\widehat f_i:\mathbb B_{64}\to\mathbb B_{64}\) 为数值函数，a 为其输入：

\[
\widehat f_{\mathrm{END}}(a)=
\begin{cases}M_q(a)&H=D,\\\mathrm{BSWAP}^{(64)}_q(a)&H\ne D,\end{cases}
\qquad
\widehat f_{\mathrm{BSWAP}}(a)=\mathrm{BSWAP}^{(64)}_q(a).
\]

q 位非负结果作为同一整数写入 64 位目标：\(\bar{E}_i=\{r_d=f_i^\star(t_d)\}\)。转换宽度决定保留的数值位数；END 的 64 位转换不能由 ALU 指令类推断为高位清零。

数值依据为 [BPF ISA](https://docs.kernel.org/bpf/standardization/instruction-set.html)。

## 跳转链接值赋值

链接值是跳转产生的返回地址赋值。控制目标绑定采用[后继位置绑定](../../NodeInference/step.md#绑定后继位置)。外部调用结果采用[Helper 生成的 Expression](../../Predicate/Helper谓词.md#生成的-expression)。

### RV32 跳转链接值

当前位置具有机器地址绑定且控制目标唯一有效时，适用链接值规则。JALR 读取执行前的基址项以确定目标。

RV32 普通 JAL、JALR 在目标不是 x0 时写指定真实目标；C.JAL、C.JALR 写真实 x1。L 为当前指令长度，普通形式 L=4、压缩形式 L=2；\(\pi\) 为当前机器地址，\(t_\pi\) 为其符号项，\(\bar{E}_i\) 为目标 \(r_d\) 的链接值关系：

\[
\widehat f_L(\pi)=M_{32}(\pi+L),
\qquad \bar{E}_i=\{r_d=f_L^\star(t_\pi)\}.
\]

位置身份与绑定见[指令序列与程序位置](../../NodeInference/路径.md)。链接值只写真实目标，不更新虚拟资源。JALR 的目标基址不参与链接公式；链接写入不能改变目标计算使用的源。

**命题（链接目标类别）。** 上述局部关系的唯一目标是指定真实寄存器。

**证明。** 规则的左侧只有 \(r_d\)，身份类别为 Real。长度 L 只改变右侧常元偏移。\(\square\)

数值依据为 [RV32I](https://docs.riscv.org/reference/isa/v20260120/unpriv/rv32.html)及 [C 扩展](https://docs.riscv.org/reference/isa/v20260120/unpriv/c-st-ext.html)。
