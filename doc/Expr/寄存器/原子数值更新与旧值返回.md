# 原子数值更新与旧值返回

原子性、并发交错、锁、内存顺序与原子观察不属于这些数值规则。

## eBPF STX ATOMIC

虚拟栈或 Map 单元已由地址源寄存器的项及指令偏移唯一确定的 eBPF STX ATOMIC，按运算与 FETCH 标志选择 \(\sigma_i=(E_i,P_i)\)，其中 \(E_i\) 是 Expr 分量，\(P_i\) 是谓词分量；构造前提采用[指令结果的前提](../Expr.md#指令结果的前提)。

q 为 32 或 64，虚拟目标标记位宽取 q。\(E_g\) 中的完整等式提供虚拟单元、源寄存器与 R0 的旧项；只有 CMPXCHG 读取 R0。
\[
r_{\mathrm{virt}}=t_{\mathrm{virt}},\qquad
r_s=t_s,\qquad r_0=t_0
\]
\(a\in\mathbb B_q\)、\(b,c\in\mathbb B_{64}\) 分别对应这些右侧项。

ADD、OR、AND、XOR 的数值签名为 \(\mathbb B_q\times\mathbb B_{64}\to\mathbb B_q\)：

- ADD：\(\widehat f_i(a,b)=M_q(a+M_q(b))\)。
- OR：\(\widehat f_i(a,b)=\mathrm{OR}_q(a,M_q(b))\)。
- AND：\(\widehat f_i(a,b)=\mathrm{AND}_q(a,M_q(b))\)。
- XOR：\(\widehat f_i(a,b)=\mathrm{XOR}_q(a,M_q(b))\)。

不带 FETCH 时，局部关系 \(E_i\) 只更新虚拟目标；\(f_i^\star\) 为所选数值函数的符号提升。
\[
E_i=\{r_{\mathrm{virt}}=f_i^\star(t_{\mathrm{virt}},t_s)\}.
\]

带 FETCH 时，\(E_i\) 同时更新虚拟目标与真实源寄存器 \(r_s\)，后者取得零扩展至 64 位的旧虚拟值。
\[
E_i=\{r_{\mathrm{virt}}=f_i^\star(t_{\mathrm{virt}},t_s),
\quad r_s=Z_{q\to64}^{(q),\star}(t_{\mathrm{virt}})\}.
\]

XCHG 的数值函数 \(\widehat f_i\) 截取源值 b 的低 q 位，签名为 \(\mathbb B_{64}\to\mathbb B_q\)。
\[
\widehat f_i(b)=M_q(b),
\]

XCHG 的 \(E_i\) 将源项 \(t_s\) 写入虚拟目标，并将旧虚拟项 \(t_{\mathrm{virt}}\) 零扩展后写入 \(r_s\)。
\[
E_i=\{r_{\mathrm{virt}}=f_i^\star(t_s),
\quad r_s=Z_{q\to64}^{(q),\star}(t_{\mathrm{virt}})\}.
\]

CMPXCHG 的 \(\widehat f_i\) 比较旧虚拟值 a 与旧 R0 值 c 的低 q 位，签名为 \(\mathbb B_q\times\mathbb B_{64}\times\mathbb B_{64}\to\mathbb B_q\)。
\[
\widehat f_i(a,b,c)=
\begin{cases}
M_q(b)&a=M_q(c),\\
a&a\ne M_q(c),
\end{cases}
\]

CMPXCHG 的 \(E_i\) 更新虚拟目标，并将旧虚拟项 \(t_{\mathrm{virt}}\) 零扩展后写入 \(r_0\)；\(t_0\) 为旧 R0 项。
\[
E_i=\{r_{\mathrm{virt}}=f_i^\star(t_{\mathrm{virt}},t_s,t_0),
\quad r_0=Z_{q\to64}^{(q),\star}(t_{\mathrm{virt}})\}.
\]

虚拟目标为 SW/SR 时归入栈输出，为 Map32/Map64 时归入 Map 输出。FETCH 决定附加的真实寄存器 Expr。更新前 \(\overline E_g\) 的取源时点采用[多目标更新与同一来源](../Expr.md#多目标更新与同一来源)。

## 旧值返回性质

**命题（旧值返回）。** 在有效规则中，FETCH、XCHG 的真实输出为更新前的虚拟值。CMPXCHG 的 R0 输出为更新前的虚拟值，与比较是否成立无关。

**证明。** 三种规则的真实输出右侧均为 \(Z_{q\to64}^{(q),\star}(t_{\mathrm{virt}})\)。所有右侧由旧 \(E_g\) 取得，虚拟目标的新值不参与该输出。CMPXCHG 的分段条件只改变虚拟输出。\(\square\)

CMPXCHG 中，旧虚拟值等于旧 R0 的低 \(q\) 位时，虚拟单元取得源低 \(q\) 位；否则保持旧值。这由分段公式直接得到。

数值依据为 [BPF ISA](https://docs.kernel.org/bpf/standardization/instruction-set.html)。
