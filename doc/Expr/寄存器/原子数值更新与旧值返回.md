# 原子数值更新与旧值返回

原子性、并发交错、锁、内存顺序与原子观察不属于这些数值规则。

## eBPF STX ATOMIC

虚拟栈或 Map 单元已由地址源寄存器的项及指令偏移唯一确定的 eBPF STX ATOMIC，按运算与 FETCH 标志选择 \(\sigma_i=(E_i,P_i)\)，其中 \(E_i\) 是 Expr 分量，\(P_i\) 是谓词分量；构造前提采用[指令结果的前提](../Expr.md#指令结果的前提)。

q 为 32 或 64。\(t_{\mathrm{virt}}\in\mathrm{Term}_q\) 是按[规范单元桥接](#规范单元桥接)从同一 \(E_g\) 取得的访问旧值视图；它不要求存在一个 q 位虚拟目标标记。源寄存器的完整旧项为 \(t_s\in\mathrm{Term}_{64}\)，CMPXCHG 还要求 R0 的完整旧项 \(t_0\in\mathrm{Term}_{64}\)。
\[
r_s=t_s,\qquad r_0=t_0.
\]
\(a\in\mathbb B_q\)、\(b,c\in\mathbb B_{64}\) 分别对应这些右侧项。下列 \(r_{\mathrm{virt}}=t'\) 表示一次访问视图写回，实际 Expr 目标及拆分由桥接规则确定。

ADD、OR、AND、XOR 的数值签名为 \(\mathbb B_q\times\mathbb B_{64}\to\mathbb B_q\)：

- ADD：\(\widehat f_i(a,b)=M_q(a+M_q(b))\)。
- OR：\(\widehat f_i(a,b)=\mathrm{OR}_q(a,M_q(b))\)。
- AND：\(\widehat f_i(a,b)=\mathrm{AND}_q(a,M_q(b))\)。
- XOR：\(\widehat f_i(a,b)=\mathrm{XOR}_q(a,M_q(b))\)。

不带 FETCH 时，局部关系 \(E_i\) 只更新虚拟目标；\(f_i^\star\) 为所选数值函数的符号提升。
\[
E_i=\{r_{\mathrm{virt}}=f_i^\star(t_{\mathrm{virt}},t_s)\}.
\]

带 FETCH 时，\(E_i\) 同时更新虚拟目标与真实源寄存器 \(r_s\)，后者取得零扩展至 64 位的旧虚拟值。
\[
E_i=\{r_{\mathrm{virt}}=f_i^\star(t_{\mathrm{virt}},t_s),
\quad r_s=Z_{q\to64}^{(q),\star}(t_{\mathrm{virt}})\}.
\]

XCHG 的数值函数 \(\widehat f_i\) 截取源值 b 的低 q 位，签名为 \(\mathbb B_{64}\to\mathbb B_q\)。
\[
\widehat f_i(b)=M_q(b),
\]

XCHG 的 \(E_i\) 将源项 \(t_s\) 写入虚拟目标，并将旧虚拟项 \(t_{\mathrm{virt}}\) 零扩展后写入 \(r_s\)。
\[
E_i=\{r_{\mathrm{virt}}=f_i^\star(t_s),
\quad r_s=Z_{q\to64}^{(q),\star}(t_{\mathrm{virt}})\}.
\]

CMPXCHG 的 \(\widehat f_i\) 比较旧虚拟值 a 与旧 R0 值 c 的低 q 位，签名为 \(\mathbb B_q\times\mathbb B_{64}\times\mathbb B_{64}\to\mathbb B_q\)。
\[
\widehat f_i(a,b,c)=
\begin{cases}
M_q(b)&a=M_q(c),\\
a&a\ne M_q(c),
\end{cases}
\]

CMPXCHG 的 \(E_i\) 更新虚拟目标，并将旧虚拟项 \(t_{\mathrm{virt}}\) 零扩展后写入 \(r_0\)；\(t_0\) 为旧 R0 项。
\[
E_i=\{r_{\mathrm{virt}}=f_i^\star(t_{\mathrm{virt}},t_s,t_0),
\quad r_0=Z_{q\to64}^{(q),\star}(t_{\mathrm{virt}})\}.
\]

虚拟访问为栈时归入栈输出，为 Map 时归入 Map 输出。FETCH 决定附加的真实寄存器 Expr。所有输出右侧使用[多目标更新与同一来源](../Expr.md#多目标更新与同一来源)取得的旧项。

## 规范单元桥接

栈的 W 访问使用已有 SW32 完整等式。栈 DW 的起点与两个规范单元采用[栈 DW 范围与单元顺序](虚拟栈.md#ebpf-的栈读写)，按地址递增将标记记为 \(r_L,r_H\)。要求同一 \(E_g\) 中同时存在完整旧等式 \(r_L=t_L\)、\(r_H=t_H\)，其中 \(t_L,t_H\in\mathrm{Term}_{32}\)。访问旧值为

\[
t_{\mathrm{virt}}:=J_{\mathrm{LE}}^\star(t_L,t_H).
\]

\(J_{\mathrm{LE}}\) 由[跨单元拼接](单元字段读写.md#ebpf-跨单元拆分与拼接)唯一定义。对上节选定的一个 q=64 位运算得到一次结果项 \(t'\in\mathrm{Term}_{64}\) 后，虚拟写回展开为

\[
E_{\mathrm{mem}}:=\{r_L=D_0^\star(t'),\ r_H=D_1^\star(t')\}.
\]

\(D_0,D_1\) 是同处定义的低、高 32 位投影。FETCH、XCHG 或 CMPXCHG 的真实输出与这两个完整单元输出同时提交。任一旧项、地址绑定或投影缺失时，整次规则无定义；栈的缺失旧值不补成输入。

Map 的规范单元保持原有 Map64 身份，记为 \(r_M\)，旧完整等式为 \(r_M=t_M\)。令 \(\ell\) 为所访问 q 位字段的最低有效位，要求 \(\ell+q\le64\)，字节偏移按 q 位访问对齐。Map W 读取该字段并转换为 32 位视图，Map DW 使用整个 Map64。其旧值定义为

\[
t_{\mathrm{virt}}:=P_{\ell,q}^{(64),\star}(t_M)\in\mathrm{Term}_q.
\]

这里 \(P\) 为[字段投影](单元字段读写.md#单元字段读写)，符号提升的结果载体为 q。所选 q 位运算取得 \(t'\) 后，实际写回为

\[
E_{\mathrm{mem}}:=\{r_M=U_{\ell,q}^{(64,q),\star}(t_M,t')\}.
\]

\(U\) 使用同处的字段覆盖定义。q=64 时完整覆盖；q=32 时字段外旧位保持，实际左值仍为同一个 Map64。访问来源的唯一性、范围、权限及已有旧内容均为前提，规则不创建同地址 Map32 别名。

**命题（一次更新与同时拆分）。** 在上述定义域内，栈 DW 的两条输出重新小端拼接后等于一次 q=64 位运算的结果。Map W 的字段输出等于一次 q=32 位运算的结果，字段外值保持。真实旧值返回取自该运算之前的同一访问视图。

**证明。** 对任意 \(x\in\mathbb B_{64}\)，欧几里得除法给出 \(x=M_{32}(x)+2^{32}\lfloor x/2^{32}\rfloor\)，高部仍属于 \(\mathbb B_{32}\)，故 \(J_{\mathrm{LE}}(D_0(x),D_1(x))=x\)。将 x 取为一次运算所得值即得栈结论。Map 结论由[字段覆盖引理 M2](单元字段读写.md#字段覆盖性质)得到。各输出均在覆写前构造，两个栈目标及真实返回目标的写入不参与任何其他右侧的取源。\(\square\)

## 旧值返回性质

**命题（旧值返回）。** 在有效规则中，FETCH、XCHG 的真实输出为更新前的虚拟值。CMPXCHG 的 R0 输出为更新前的虚拟值，与比较是否成立无关。

**证明。** 三种规则的真实输出右侧均为 \(Z_{q\to64}^{(q),\star}(t_{\mathrm{virt}})\)。所有右侧由旧 \(E_g\) 取得，虚拟目标的新值不参与该输出。CMPXCHG 的分段条件只改变虚拟输出。\(\square\)

CMPXCHG 中，旧虚拟值等于旧 R0 的低 \(q\) 位时，虚拟单元取得源低 \(q\) 位；否则保持旧值。这由分段公式直接得到。

数值依据为 [BPF ISA](https://docs.kernel.org/bpf/standardization/instruction-set.html)。
