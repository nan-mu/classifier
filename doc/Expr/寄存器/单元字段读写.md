# 单元字段读写

Stack、Map 与 Context 共用规范单元的字段数值函数，对象身份见[寄存器定义](../../寄存器定义.md)。访问对象及单元内字节偏移由指令集侧的地址绑定根据地址源寄存器的项与指令偏移确定；RV32 上下文字段采用[入口假设 II](../../NodeInference/create.md#上下文六槽关系)。

访问位宽为 \(q\)，由指令宽度字段确定；单元位宽为 \(w\)，字段最低有效位位置为 \(\ell\)，满足 \(0\le\ell\)、\(\ell+q\le w\)。字节序由访问形式确定。单元内字节偏移 d 在 LE 下为 \(\ell=8d\)，在 BE 下为 \(\ell=w-q-8d\)。

\(P_{\ell,q}^{(w)}\) 投影单元值 \(a\in\mathbb B_w\) 的 q 位字段；\(M_q\) 为[模归一化函数](../Term/位向量.md#位向量)。
\[
P_{\ell,q}^{(w)}(a)
=M_q\!\left(\left\lfloor a/2^\ell\right\rfloor\right).
\]

旧单元等式为 \(r_v=t_v\)，真实目标 \(r_d\) 的位宽为 \(v\)，要求 \(q\le\min(w,v)\)。\(\widehat R_Z\)、\(\widehat R_S\) 分别对字段作[零扩展、符号扩展](../Term/数值函数.md#截取与扩展)。
\[
\widehat R_Z(a)=Z_{q\to v}^{(w)}(P_{\ell,q}^{(w)}(a)),
\qquad
\widehat R_S(a)=S_{q\to v}^{(w)}(P_{\ell,q}^{(w)}(a)),
\]
读取输出 \(\{r_d=R_Z^\star(t_v)\}\) 或 \(\{r_d=R_S^\star(t_v)\}\)；\(\star\) 为[数值函数的符号提升](../Expr.md#部分值函数与符号提升)。

源值 \(b\in\mathbb B_v\)，且 \(q\le v\)。\(U\) 用 b 的低 q 位替换旧单元值 a 的字段；\(t_s\) 为源项，\(E_i\) 为写入局部关系。
\[
U_{\ell,q}^{(w,v)}(a,b)
=a-2^\ell P_{\ell,q}^{(w)}(a)+2^\ell M_q(b),
\qquad
E_i=\{r_v=U_{\ell,q}^{(w,v),\star}(t_v,t_s)\}.
\]

完整写入 \((\ell,q)=(0,w)\) 时，结果为 \(M_w(b)\)，采用只含源项的函数，无需目标旧值。部分写入需要完整旧值。新等式覆写完整单元。

跨规范单元访问须有唯一的分段与组合规则，不能默认为单个单元的低位写入。

## 字段覆盖性质

**引理 M2（Stack/Map/Context 字段覆盖）。** \(a'=U_{\ell,q}^{(w,v)}(a,b)\) 属于 \(\mathbb B_w\)。目标字段为 \(M_q(b)\)，字段外各位保持旧值。

**证明。** 唯一分解为 \(a=h2^{\ell+q}+c2^\ell+d\)，其中 \(c\in\mathbb B_q\)、\(0\le d<2^\ell\)。U 将 c 替换为 \(M_q(b)\)，保留 h、d。新各段宽度不变，故仍属于 \(\mathbb B_w\)。\(\ell=0\) 时取 d=0。\(\square\)

## 同位宽传值

虚拟单元 \(r_v\in\mathrm{Reg}_w\) 已有完整等式 \(r_v=t\) 时，读取到真实寄存器 \(r_d\) 产生 \(r_d=t\)。反向写入使用源真实寄存器的旧项，产生 \(r_v=t_s\)。

目标须为地址源寄存器的项与指令偏移实际确定的一个单元，源值须满足目标类别的值域约束。不同类别标记为不同目标。源项的值由执行前关系确定。Stack/Map/Context 字段访问采用 U；Packet 访问采用[包字节规则](包字节.md#包字节读写)，每个目标为一个包字节。

## 访问参数与源项

取源采用[多目标更新与同一来源](../Expr.md#多目标更新与同一来源)。构造前提采用[指令结果的前提](../Expr.md#指令结果的前提)。

### RV32

地址源寄存器的项与指令偏移确定访问 Stack、Map 或 Context 单元的 RV32 普通读取，LB/LH 选择 \(R_S\)，LBU/LHU/LW 选择 \(R_Z\)。

SB、SH、SW 分别写 8、16、32 位，C.SW、C.SWSP 写 32 位，真实源项宽度为 32。完整覆盖只可能发生在 q=w=32；写 SR、Map64 或 Context64 的 32 位字段仍须保留字段外旧位。

### eBPF

地址源寄存器的项与指令偏移确定访问 Stack、Map 或 Context 单元的 eBPF LDX 读取，MEMSX 选择 \(R_S\)，MEM 选择 \(R_Z\)。

普通 ST、STX、STORE_REL 可写 8、16、32、64 位，真实源项宽度为 64。ST 由[立即数规则](真实寄存器.md#常元赋值)取得符号扩展源项。STX、STORE_REL 读取实际源寄存器的完整等式。STORE_REL 使用相同数值覆盖函数，release 或原子观察未定义。

## 共同访问规则

低位写入是 U 的 \(\ell=0\) 情形。32 位单元旧值为 \(\mathtt{0x10000}\) 时，16 位写入 1 后为 \(\mathtt{0x10001}\)。字段覆盖引理保证旧高位保持；[真实 ALU32 写回](真实寄存器.md#真实寄存器低位视图与写回)将完整目标高位清零。

Stack、Map 与 Context 的目标类别由指令集侧的地址绑定根据地址源寄存器的项与指令偏移确定。访问对象与实际操作数的一致性、资源有效性、访问观察及跨单元一致性须独立论证。数值依据为 [RV32I](https://docs.riscv.org/reference/isa/v20260120/unpriv/rv32.html)、[BPF ISA](https://docs.kernel.org/bpf/standardization/instruction-set.html)及 [LLVM 扩展定义](https://llvm.googlesource.com/llvm-project/+/17bfc00f7c4a424d7b5dc6da575865833701fd1a%5E%21/)。
