# 虚拟栈

## 虚拟栈读写

地址源寄存器的项与指令偏移唯一确定所访问的栈资源及其规范单元。固定 xdp_md 上下文字段的地址确定 Context 类别的单元，读写采用[共同规范单元字段规则](单元字段读写.md#单元字段读写)；地址到单元的绑定采用[入口假设 II](../../NodeInference/create.md#上下文六槽关系)。

栈标识 \(\alpha=(\phi,u)\) 中，\(\phi\) 区分栈资源，\(u\) 区分规范单元。

LOAD 从 Stack 取值，只写真实目标。普通 STORE 向 Stack 写值，只写 SW/SR；基址或数据源真实寄存器保持原值。同时写回旧值的特殊访问采用[原子数值更新与旧值返回](原子数值更新与旧值返回.md#原子数值更新与旧值返回)。

读取使用栈单元的完整等式。普通写入使用数据源项，部分写入还要求栈单元的完整旧值。成功时按[字段规则](单元字段读写.md#单元字段读写)生成真实目标或 SW/SR 的完整等式 \(E_i\)；取源与构造前提采用[访问参数与源项](单元字段读写.md#访问参数与源项)。

## 架构对应（虚拟栈读写）

### RV32 的栈读写

以 SP 或其已知别名寻址的 LOAD/STORE，可归入 Stack。调整 SP 后的别名标记见[寄存器定义](../../寄存器定义.md)。合法压缩栈读写使用普通字访问的值规则。

LOAD/STORE 可以访问已确定的栈资源中尚无完整等式的虚拟寄存器，采用[未记录虚拟寄存器的取源](../Expr.md#未记录虚拟寄存器的取源)。

### eBPF 的栈读写

以 \(r_{10}\) 或其已知别名寻址的 LDX/ST/STX，可归入 Stack。

LDX/ST/STX 可以访问已确定的栈资源中尚无完整等式的虚拟寄存器，采用[未记录虚拟寄存器的取源](../Expr.md#未记录虚拟寄存器的取源)。
