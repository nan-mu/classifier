# 虚拟栈

## 虚拟栈读写

地址源寄存器的项与指令偏移唯一确定所访问的栈资源及其规范单元。固定 xdp_md 上下文字段的地址确定 Context 类别的单元，读写采用[共同规范单元字段规则](单元字段读写.md#单元字段读写)；地址到单元的绑定采用[入口假设 II](../../NodeInference/create.md#上下文六槽关系)。

栈标识 \(\alpha=(\phi,u)\) 中，\(\phi\) 区分栈资源，\(u\) 区分规范单元。

LOAD 从 Stack 取值，只写真实目标。普通 STORE 向 Stack 写值，只写 SW/SR；基址或数据源真实寄存器保持原值。同时写回旧值的特殊访问采用[原子数值更新与旧值返回](原子数值更新与旧值返回.md#原子数值更新与旧值返回)。

读取使用栈单元的完整等式。普通写入使用数据源项，部分写入还要求栈单元的完整旧值。成功时按[字段规则](单元字段读写.md#单元字段读写)生成真实目标或 SW/SR 的完整等式 \(E_i\)；取源与构造前提采用[访问参数与源项](单元字段读写.md#访问参数与源项)。

## 架构对应（虚拟栈读写）

### RV32 的栈读写

以 SP 或其已知别名寻址的 LOAD/STORE，可归入 Stack。调整 SP 后的别名标记见[寄存器定义](../../寄存器定义.md)。合法压缩栈读写使用普通字访问的值规则。

LOAD/STORE 可以访问已确定的栈资源中尚无完整等式的虚拟寄存器，采用[未记录虚拟寄存器的取源](../Expr.md#未记录虚拟寄存器的取源)。

### eBPF 的栈读写

以 \(r_{10}\) 或其根相对别名寻址的 LDX/ST/STX，可归入 Stack。入口帧指针项 \(t_{\mathrm{sp}}\) 与资源身份 \(\phi_{\mathrm{stack}}\in\mathbb N\) 采用[eBPF 入口参数](../../NodeInference/create.md#入口项与位宽条件)，\(r_{10}\) 的只读限制采用[真实寄存器赋值](真实寄存器.md#ebpf真实寄存器赋值)。

令 \(s\) 为 \(t_{\mathrm{sp}}\) 在给定入口变元赋值下的无符号地址解释，并假设 \(512\le s<2^{64}\)。栈区域为

\[
\mathcal S_{\phi_{\mathrm{stack}}}:=[s-512,s).
\]

对 \(u\in\{0,\ldots,127\}\)，规范单元的四字节区间为

\[
U_u:=[s-4(u+1),s-4u).
\]

这 128 个区间两两不交，按地址递增的相邻端点衔接，合起来恰为栈区域。单元 0 从 \(s-4\) 开始，单元 127 从 \(s-512\) 开始。单元划分不随访问宽度改变。

单元 \(u\) 的起始地址项为

\[
A_u:=\mathrm{ADD}_{64}^{\star}
(t_{\mathrm{sp}},C_{64}(M_{64}(-4(u+1)))).
\]

\(\mathrm{ADD}\) 与 \(M\) 采用[共同数值函数](../Term/数值函数.md#算术)。在上述不回绕假设下，\(A_u\) 的解释就是 \(s-4(u+1)\)，即相对帧指针的地址 \(t_{\mathrm{sp}}-4(u+1)\)。

栈单元身份 \((\phi_{\mathrm{stack}},u)\) 以自然数编码

\[
\alpha(\phi_{\mathrm{stack}},u):=128\phi_{\mathrm{stack}}+u.
\]

对应的值标记为 \(\mathrm{SW}(\alpha(\phi_{\mathrm{stack}},u))\)。由于 \(0\le u<128\)，对编码值作除以 128 的商余分解，分别恢复 \(\phi_{\mathrm{stack}}\) 与 \(u\)，故编码在所有合法身份上单射。DW 访问仍使用两个 SW 标记，不新增独立的 SR 标记；顺序原子 DW 的同源拼装、一次更新与同时拆分见[规范单元桥接](原子数值更新与旧值返回.md#规范单元桥接)。

设执行前完整基址项相对 \(t_{\mathrm{sp}}\) 的位移加上指令偏移后为 \(d\in\mathbb Z\)，访问字节数为 \(b\in\{1,2,4,8\}\)。栈范围条件为

\[
-512\le d<0,\qquad d+b\le0.
\]

根相对位移与资源唯一分类采用[资源入口绑定](../../NodeInference/create.md#资源入口绑定)。若起始地址为 \(A_u\) 加单元内字节偏移 \(h\in\{0,1,2,3\}\)，B/H/W 访问分别取 \(b=1,2,4\)，并要求 \(h+b\le4\)。字段起点为 \(\ell=8h\)，字段宽度为 \(q=8b\)。DW 要求 \(h=0\)、\(1\le u<128\)，依地址递增顺序访问单元 \(u\)、\(u-1\)；低地址单元承载结果的低 32 位。

普通 LDX MEM 从每个所需 SW 完整等式读取字段。B/H 读取相应字段后零扩展至 64 位；W 读取一个完整 32 位单元后零扩展至 64 位；DW 从两个连续完整单元按[小端跨单元规则](单元字段读写.md#ebpf-跨单元拆分与拼接)拼成 64 位项。读取成功只写实际真实目标，所有栈内容保持不变。

普通写入的源项取自同一执行前关系。W 写入完整单元，只使用源项低 32 位，无需该单元旧值。B/H 及其他部分字段写入要求已有完整旧单元等式，以保留字段外各位。DW 将源项拆成两个完整 32 位单元，一次提交两个目标等式，两个单元均无需旧值。任一部分失败时整次写入无定义，不得提交半个 DW。

完整写入与部分覆盖采用[共同字段函数](单元字段读写.md#单元字段读写)，多目标的取源和提交采用[同一执行前关系规则](单元字段读写.md#ebpf-跨单元拆分与拼接)。共享 [Core/Virtual.lean](../../../Core/Virtual.lean) 的 `CellAccess.read` 要求完整旧等式，`CellAccess.write` 仅在完整覆盖时免除旧值要求；eBPF 的单元解析采用 [EBPF/Memory.lean](../../../EBPF/Memory.lean)。

以下情况使栈访问无定义：

- 完整地址源或写入数据源缺失、位宽不符，或执行前关系的键不唯一。
- 读取所需的任一旧单元值缺失；部分写入所需的完整旧值缺失。
- 访问超出栈区域；B/H/W 跨越单元边界；DW 的起点不在单元边界或缺少第二个区域内单元。
- 无法确定根相对位移，或 Context、Stack、Packet 的资源分类候选数不等于一。

未初始化栈内容没有首次读取输入契约，不能依[未记录虚拟寄存器的取源](../Expr.md#未记录虚拟寄存器的取源)补任意值；完整单元写入可直接建立其等式。执行环境的资源权限、对齐等有效性条件采用[入口外部假设](../../NodeInference/create.md#外部假设与初态边界)。普通指令的数学规则不扩大现有有限实现的指令覆盖范围，覆盖边界见[工程模块与迁移](../../NodeInference/路径合并FFI.md#工程模块与迁移)。
