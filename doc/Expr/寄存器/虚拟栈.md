# 虚拟栈

## 虚拟栈读写

地址源寄存器的项与指令偏移唯一确定栈上的位区间 \([b,e)\)。寄存器就是 \(\operatorname{Stack}([b,e))\)，见[寄存器定义](../../寄存器定义.md)。固定 \(\mathrm{xdp\_md}\) 字段的地址确定 \(\operatorname{Context}(j,[b,e))\)，读写采用[字段规则](单元字段读写.md#单元字段读写)；地址到字段的绑定采用[入口假设 II](../../NodeInference/create.md#上下文六槽关系)。

LOAD 从栈区间取值，只写真实目标。普通 STORE 只写选定的栈区间；基址或数据源真实寄存器保持原值。相交的旧等式按[重叠区间](../../寄存器定义.md#重叠区间的读和写)拆开。同时写回旧值的特殊访问采用[原子数值更新与旧值返回](原子数值更新与旧值返回.md#原子数值更新与旧值返回)。

读取把盖住 \([b,e)\) 的片段拼起来；有空洞则没有定义。恰好有一条同区间等式时直接使用它。成功时按[字段规则](单元字段读写.md#单元字段读写)生成真实目标或该栈区间的等式 \(\bar{E}_i\)；取源与构造前提采用[访问参数与源项](单元字段读写.md#访问参数与源项)。

## 架构对应（虚拟栈读写）

### RV32 的栈读写

以 SP 或其已知别名寻址的 LOAD/STORE，可归入 Stack。调整 SP 只改真实寄存器，不改已经写下的栈区间。合法压缩栈读写使用普通字访问的值规则。

LOAD/STORE 可以访问已确定的栈资源中尚无完整等式的虚拟寄存器，采用[未记录虚拟寄存器的取源](../Expr.md#未记录虚拟寄存器的取源)。

### eBPF 的栈读写

以 \(r_{10}\) 或其根相对别名寻址的 LDX/ST/STX，可归入 Stack。入口帧指针项 \(t_{\mathrm{sp}}\) 采用[eBPF 入口参数](../../NodeInference/create.md#入口项与位宽条件)，\(r_{10}\) 的只读限制采用[真实寄存器赋值](真实寄存器.md#ebpf真实寄存器赋值)。入口把 \(\operatorname{Real}(10,[0,64))\) 和 \(\operatorname{Context}(\mathrm{sp},[0,64))\) 都设为 \(t_{\mathrm{sp}}\)。后来对 \(r_{10}\) 的成功规则不存在；冻结的 \(\mathrm{sp}\) 字段不随真实寄存器变化。

令 \(s\) 为 \(t_{\mathrm{sp}}\) 在给定入口变元赋值下的无符号地址解释，并假设 \(512\le s<2^{64}\)。允许命名的地址范围是 \([s-512,s)\)。一次访问不按 128 个四字节单元编号。它只产生一个 \(\operatorname{Stack}([b,e))\)，宽度 \(e-b\) 等于访问的位数。bit 0 取这个地址范围的低地址端，使字节偏移 \(o\) 对应位区间 \([8o,8o+q)\)。

设执行前完整基址项相对 \(t_{\mathrm{sp}}\) 的位移加上指令偏移后为 \(d\in\mathbb Z\)，访问字节数为 \(b\in\{1,2,4,8\}\)。栈范围条件为

\[
-512\le d<0,\qquad d+b\le0.
\]

根相对位移与资源唯一分类采用[资源入口绑定](../../NodeInference/create.md#资源入口绑定)。满足范围时，低地址端相对 \(s-512\) 的字节偏移确定 \(b\) 的起点，寄存器宽度为 \(8b\) 位。顺序原子的 64 位访问使用这一个 64 位区间；若旧值只以相邻的 32 位区间存在，按[重叠读取](../../寄存器定义.md#重叠区间的读和写)拼接，再把结果拆回那些区间。数值拼接见[旧值拼接](原子数值更新与旧值返回.md#规范单元桥接)。

普通 LDX 读取该区间后，按访问宽度零扩展或符号扩展到真实目标。读取成功只写实际真实目标。普通写入的源项取自同一执行前关系，写入这一个栈区间；与它相交的旧等式拆成两侧投影。任一部分无法读取时整次访问无定义。

字段投影与覆盖的数值函数见[单元字段读写](单元字段读写.md#单元字段读写)。多目标的取源和提交采用[同一执行前关系规则](单元字段读写.md#ebpf-跨单元拆分与拼接)。

以下情况使栈访问无定义：

- 完整地址源或写入数据源缺失、位宽不符，或执行前关系的键不唯一。
- 读取所需的位区间有空洞，或写入无法从旧项切出两侧剩余位。
- 访问超出 \([s-512,s)\)。
- 无法确定根相对位移，或 Context、Stack、Packet 的资源分类候选数不等于一。

未初始化栈内容没有首次读取输入契约，不能依[未记录虚拟寄存器的取源](../Expr.md#未记录虚拟寄存器的取源)补任意值；完整单元写入可直接建立其等式。执行环境的资源权限、对齐等有效性条件采用[入口外部假设](../../NodeInference/create.md#外部假设与初态边界)。普通指令的数学规则不扩大现有有限实现的指令覆盖范围，覆盖边界见[工程模块与迁移](../../NodeInference/路径合并FFI.md#工程模块与迁移)。
