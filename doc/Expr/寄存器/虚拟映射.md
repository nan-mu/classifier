# 虚拟映射

## 虚拟映射读写

lookup 保存的键字节项序列记作 \(\bar k\)。此后该条目的值使用寄存器 \(\operatorname{Map}(m,\bar k,[b,e))\)，其中 \(m\) 是 Map 标识，\([b,e)\) 是值内的位区间。身份见[寄存器定义](../../寄存器定义.md)。仅有地址数值、Map 编号或访问指令时，\(\bar k\) 仍未确定，不能构造这个寄存器。

Map 区间的读取只写真实目标。普通写入只写选定的 \(\operatorname{Map}(m,\bar k,[b,e))\)。与它相交的旧等式按[重叠区间](../../寄存器定义.md#重叠区间的读和写)拆开：相交的位换成新项，两侧剩下的位是旧项的投影。字段投影、零扩展与符号扩展的数值函数采用[单元字段读写](单元字段读写.md#单元字段读写)。访问对象由地址源寄存器里的 Map 引用项与指令偏移确定。取源与构造前提采用[访问参数与源项](单元字段读写.md#访问参数与源项)。

键长和值长从 \(\operatorname{Context}(\mathrm{mapKeyBytes}(m),[0,32))\) 与 \(\operatorname{Context}(\mathrm{mapValueBytes}(m),[0,32))\) 读取。值内位区间不得超过值的位数。\(\bar k\) 的长度必须等于键字节数，每一项是调用当时的一个键字节。

同时写回旧值的特殊访问采用[原子数值更新与旧值返回](原子数值更新与旧值返回.md#原子数值更新与旧值返回)。64 位值上的字段更新保持同一 \((m,\bar k)\)，只改变位区间。

## 架构对应（虚拟映射读写）

### RV32 的 Map 读写

Map 来源已确定的 LOAD/STORE，归入 Map。

LOAD/STORE 可以访问已确定的 Map 值中尚无等式盖住的区间。有空洞时读取没有定义，不补任意字节。

### eBPF 的 Map 读写

Map 来源已确定的 LDX/ST/STX，归入 Map。

LDX/ST/STX 可以访问已确定的 Map 值中尚无等式盖住的区间。有空洞时读取没有定义，不补任意字节。
