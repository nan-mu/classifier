# 虚拟映射

## 虚拟映射读写

lookup 返回的关联采用[Helper 生成的 Expression](../../Predicate/Helper谓词.md#生成的-expression)。Map 标识 \(\alpha=(\mu,\eta,u)\) 中，\(\mu\) 标识 Map 对象，\(\eta\) 标识条目，\(u\) 标识该条目中的规范单元。

同一单元的别名标记与条目身份见[寄存器定义](../../寄存器定义.md)。仅有地址数值、Map 编号或访问指令时，条目身份仍未确定。

Map 单元读取只写真实目标；普通写入只写 Map32/Map64。字段投影、零扩展、符号扩展及字段覆盖采用[单元字段读写](单元字段读写.md#单元字段读写)，访问对象与 Expression 左侧类别由地址源寄存器的 Map 引用项与指令偏移确定。取源与构造前提采用[访问参数与源项](单元字段读写.md#访问参数与源项)。

已绑定 \(\mathrm{Map}_{64}(\mu,\eta,u)=t_v\) 的低 32 位写入，以 \(t_s\) 为源项，局部关系 \(\bar{E}_i\) 为
\[
\bar{E}_i=\{\mathrm{Map}_{64}(\mu,\eta,u)
=U_{0,32}^{(64,v),\star}(t_v,t_s)\}.
\]
字段外旧位由[字段覆盖性质](单元字段读写.md#字段覆盖性质)保持。真实目标的 ALU32 写回采用[真实寄存器低位视图与写回](真实寄存器.md#真实寄存器低位视图与写回)。

同时写回旧值的特殊访问采用[原子数值更新与旧值返回](原子数值更新与旧值返回.md#原子数值更新与旧值返回)，其中 W 访问在原 Map64 上读写字段，具体[视图桥接](原子数值更新与旧值返回.md#规范单元桥接)保持单元身份。

## 架构对应（虚拟映射读写）

### RV32 的 Map 读写

Map 来源已确定的 LOAD/STORE，归入 Map。

LOAD/STORE 可以访问已确定的 Map 资源中尚无完整等式的虚拟寄存器，采用[未记录虚拟寄存器的取源](../Expr.md#未记录虚拟寄存器的取源)。

### eBPF 的 Map 读写

Map 来源已确定的 LDX/ST/STX，归入 Map。

LDX/ST/STX 可以访问已确定的 Map 资源中尚无完整等式的虚拟寄存器，采用[未记录虚拟寄存器的取源](../Expr.md#未记录虚拟寄存器的取源)。
