# 乘法高半赋值

乘法低半采用[共同 MULLO 函数](位向量与共同数值函数.md#算术)。本规则只讨论高半结果，参数顺序和有符号解释由指令确定。

RV32 的 rs1、rs2 提供旧源项 \(t_a,t_b\in\mathrm{Term}_{32}\)。三个数值函数的签名均为 \(\mathbb B_{32}^2\to\mathbb B_{32}\)：

\[
\begin{aligned}
\widehat f_{\mathrm{HU}}(a,b)&=M_{32}(\lfloor ab/2^{32}\rfloor),\\
\widehat f_{\mathrm{H}}(a,b)&=M_{32}(\lfloor s_{32}(a)s_{32}(b)/2^{32}\rfloor),\\
\widehat f_{\mathrm{HSU}}(a,b)&=M_{32}(\lfloor s_{32}(a)b/2^{32}\rfloor).
\end{aligned}
\]

MULHU、MULH、MULHSU 分别采用上述函数，局部关系为 \(E_i=\{r_d=f_i^\star(t_a,t_b)\}\)。MULHSU 的第一源有符号、第二源无符号，不能交换。高半计算使用向下取整，再取 32 位模式；其数学中间乘积不增加 64 位真实寄存器身份。

数值依据为 [M 扩展](https://docs.riscv.org/reference/isa/v20260120/unpriv/m-st-ext.html)。
