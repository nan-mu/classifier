# 算术与位运算赋值

本规则将纯数值函数提升为真实寄存器的赋值。数值公式集中在[位向量与共同数值函数](位向量与共同数值函数.md)，符号提升与部分求值采用[符号项求值与常量折叠](符号项求值与常量折叠.md)。指令参数须满足[合法域](../NodeInference/指令参数与规则定义域.md)。

设运算宽度为 \(q\in\{32,64\}\)，源项承载宽度为 \(v\)，满足 \(q\le v\)。对共同二元函数 \(G_q\)，定义

\[
\widehat f_{G,q,v}(a,b)=G_q(M_q(a),M_q(b)),
\qquad f_{G,q,v}:\mathbb B_v^2\to\mathbb B_v.
\]

结果作为同一非负整数放入 \(\mathbb B_v\)。局部关系为

\[
E_i=\{r_d=f_{G,q,v}^{\star}(t_a,t_b)\}.
\]

共同运算为 ADD、SUB、MULLO、AND、OR、XOR、SHL、LSHR、ASHR；移位量由第二源低位给出，再模 q。算术右移使用向下取整，不使用向零商。所有右侧从[同一源快照](多目标更新与同一源快照.md)取得。

## 源项与助记符的对应

RV32 取 \(q=v=32\)。普通双源指令读取 rs1、rs2，不默认读取 rd 的旧值。MUL 使用 MULLO；SLL、SRL、SRA 分别使用 SHL、LSHR、ASHR。SLT、SLTU 使用共同的 LTS、LTU，写回 0 或 1；这些结果是 Expr，不是分支 Predicate。

立即数形式将 \(I=M_{32}(\iota)\) 固定在函数内，只读取一个寄存器源：ADDI、ANDI、ORI、XORI 分别使用 ADD、AND、OR、XOR；SLTI、SLTIU 使用 LTS、LTU。SLTIU 的立即数先符号扩展，再按无符号模式比较。SLLI、SRLI、SRAI 固定合法的 \(0\le k<32\)。相应输出为 \(\{r_d=f_i^\star(t_a)\}\)。

eBPF 取 \(v=64\)，运算宽度 q 为 32 或 64。二元运算读取目标旧项 \(t_d\) 和源项 \(t_{\mathrm{src}}\)，输出使用上式的 \(t_a=t_d\)。寄存器源提供已有完整等式的右侧；立即数源采用[常元赋值](常元赋值.md)的立即数项。MUL、LSH、RSH、ARSH 分别对应 MULLO、SHL、LSHR、ASHR。q=32 的结果作为 64 位值写回，见[真实寄存器低位视图与写回](真实寄存器低位视图与写回.md)。

## 采用相同函数的压缩形式

合法、非 HINT 的压缩形式使用上面的 32 位函数，只改变取源和目标：

- C.ADDI4SPN 读取 x2 并写指定目标；C.ADDI 读取并写同一目标；C.ADDI16SP 读取并写 x2。三者使用固定立即数的 ADD。
- C.SRLI、C.SRAI、C.SLLI、C.ANDI 读取并写同一目标，分别使用固定参数的 LSHR、ASHR、SHL、AND。
- C.SUB、C.XOR、C.OR、C.AND、C.ADD 读取目标旧项和另一源项，分别使用 SUB、XOR、OR、AND、ADD，并写回该目标。

C.MV 见[移动与符号扩展赋值](移动与符号扩展赋值.md)；C.LI、C.LUI 见[常元赋值](常元赋值.md)。C.ADDI16SP 修改真实 x2；C.ADDI4SPN 只计算真实目标。两者都不自动新增或写入虚拟栈单元。

数值依据为 [RV32I](https://docs.riscv.org/reference/isa/v20260120/unpriv/rv32.html)、[M 扩展](https://docs.riscv.org/reference/isa/v20260120/unpriv/m-st-ext.html)、[C 扩展](https://docs.riscv.org/reference/isa/v20260120/unpriv/c-st-ext.html)及 [BPF ISA](https://docs.kernel.org/bpf/standardization/instruction-set.html)。

## 一元取负与当前位置加常元

NEG 是一元取负，读取目标旧项 \(t_d\)，使用 \(\widehat f(a)=\mathrm{NEG}_q(M_q(a))\)，输出 \(\{r_d=f^\star(t_d)\}\)。这里 eBPF 仍取 v=64；目标旧项的要求不能套用到[移动赋值](移动与符号扩展赋值.md)。

AUIPC 的 U 采用[常元赋值](常元赋值.md)中 LUI 的同一个上位常元。AUIPC 使用 \(\widehat f(\pi)=\mathrm{ADD}_{32}(\pi,U)\)，输出 \(\{r_d=f^\star(t_\pi)\}\)。\(t_\pi\) 必须描述当前指令位置，不能沿用上一次位置项；位置身份与绑定见[指令序列与程序位置](../NodeInference/指令序列与程序位置.md)。
