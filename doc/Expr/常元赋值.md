# 常元赋值

常元赋值不读取目标旧值。目标是否合法以及固定、只读寄存器如何处理，见[真实寄存器赋值](真实寄存器赋值.md)。立即数与槽位参数须满足[规则合法域](../NodeInference/指令参数与规则定义域.md)。

给定完整常元 \(c\in\mathbb B_v\)，局部关系为 \(E_i=\{r_d=C_v(c)\}\)。立即数的解释随参数形式而异：

- RV32 LUI 使用满足 \(M_{12}(U)=0\) 的 \(U\in\mathbb B_{32}\)。C.LI 使用 \(M_{32}(\iota)\)；C.LUI 使用 \(U_C=M_{32}(s_6(h)2^{12})\)。三者都不读目标旧值。
- eBPF 的 32 位立即数模式 \(\iota\) 形成源项 \(t_{\mathrm{imm}}=C_{64}(M_{64}(s_{32}(\iota)))\)。MOV 立即数按运算宽度 q 写回 \(C_{64}(M_q(s_{32}(\iota)))\)。
- 普通 LDDW 的配对槽位提供 \(\iota_0,\iota_1\in\mathbb B_{32}\)，完整常元为 \(C_{64}(\iota_0+2^{32}\iota_1)\)。其他 LDDW 子类型不由这个常元公式确定，见[资源读取与位置赋值](资源读取与位置赋值.md)。

立即数与配对参数的合法范围见[指令参数与规则定义域](../NodeInference/指令参数与规则定义域.md)。

数值依据为 [RV32I](https://docs.riscv.org/reference/isa/v20260120/unpriv/rv32.html)、[C 扩展](https://docs.riscv.org/reference/isa/v20260120/unpriv/c-st-ext.html)及 [BPF ISA](https://docs.kernel.org/bpf/standardization/instruction-set.html)。
