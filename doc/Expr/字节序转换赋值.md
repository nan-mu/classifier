# 字节序转换赋值

字节反转的数值公式见[共同数值函数](位向量与共同数值函数.md#字节反转)。本规则确定转换结果如何写回真实目标，不涉及资源地址绑定。

eBPF END、BSWAP 使用转换宽度 \(q\in\{16,32,64\}\)。D 为 END 指定的 LE 或 BE，H 为模型的固定字节序。由旧等式取得 \(r_d=t_d\)，定义 \(\widehat f_i:\mathbb B_{64}\to\mathbb B_{64}\)：

\[
\widehat f_{\mathrm{END}}(a)=
\begin{cases}M_q(a)&H=D,\\\mathrm{BSWAP}^{(64)}_q(a)&H\ne D,\end{cases}
\qquad
\widehat f_{\mathrm{BSWAP}}(a)=\mathrm{BSWAP}^{(64)}_q(a).
\]

q 位非负结果作为同一整数写入 64 位目标：\(E_i=\{r_d=f_i^\star(t_d)\}\)。转换宽度决定保留的数值位数；END 的 64 位转换不能由 ALU 指令类推断为高位清零。

数值依据为 [BPF ISA](https://docs.kernel.org/bpf/standardization/instruction-set.html)。
