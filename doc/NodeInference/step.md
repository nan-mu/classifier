# step

## create

create 构造初始语义状态，具体初态由[create](create.md)维护。

## step

step 负责一条指令的局部语义，接收执行前的状态 \(\sigma_g\)，返回拒绝结果或候选数组；每项携带方向、后继指令序号与局部语义增量。

### 局部推理接口

#### 输入

输入 \(\mathbf I\) 为指令序列，\(j\) 为当前指令的序号，二者见[指令序列与程序位置](路径.md#指令序列与程序位置)；索引空间的区别见[程序位置](路径.md#程序位置)。\(\sigma_g=(E_g,P_g)\) 为当前指令执行前的语义状态，见[语义状态](#语义状态)。

\[
\operatorname{Input}=(\mathbf I,j,\sigma_g)
\]

具体地，\(\mathbf I=(i_0,\ldots,i_{m-1})\in\mathrm{Insn}^{\ast}\)，当前位置 \(j\in\mathrm{Pos}_{\mathbf I}=\{j\in\mathbb N:1\le j\le m\}\)，该位置的指令为 \(\mathbf I[j-1]=i_{j-1}\)；后继位置域为 \(\mathrm{Loc}_{\mathbf I}=\mathrm{Pos}_{\mathbf I}\sqcup\{\mathrm{Exit}\}\)，其中 Exit 不属于 \(\mathrm{Pos}_{\mathbf I}\)。Step 接收当前指令执行前的状态 \(\sigma_g=(E_g,P_g)\)。控制目标绑定与当前指令的位置绑定是本步的前提。

\[
\begin{aligned}
\mathbf I&=(i_0,\ldots,i_{m-1})\in\mathrm{Insn}^{\ast},
\qquad m=|\mathbf I|,\\
j&\in\mathrm{Pos}_{\mathbf I}=\{j\in\mathbb N:1\le j\le m\},\\
\sigma_g&=(E_g,P_g)\in\mathrm{State},\\
\mathrm{Loc}_{\mathbf I}&=\mathrm{Pos}_{\mathbf I}\sqcup\{\mathrm{Exit}\},\\
\end{aligned}
\]

\[
\begin{aligned}
\operatorname{Step}(\mathbf I,\cdot,\cdot)&:
\mathrm{Pos}_{\mathbf I}\times\mathrm{State}\\
&\longrightarrow
\{\operatorname{Reject}(a)\mid a\text{ 为拒绝原因}\}\\
&\qquad\sqcup
\left\{\operatorname{Candidates}\bigl([(d_1,j_1,\sigma_1),
\ldots,(d_c,j_c,\sigma_c)]\bigr)
\ \middle|\ c\in\mathbb N,\ \text{各分量满足输出的取值范围}\right\}.
\end{aligned}
\]

\(m\) 为序列长度，\(\mathrm{Insn}\) 与 \(\mathrm{Exit}\) 见[指令序列与程序位置](路径.md#指令序列与程序位置)；\(\mathrm{State}\) 见[语义状态](#语义状态)，输入分量 \(E_g,P_g\) 分别对应该类型的 \(\mathcal E,\mathcal P\)；Step 的结果见[两种结果](#两种结果)，其中 \(c\) 为候选数，\(a\) 与各输出分量的含义和取值范围见[输出](#输出)。

Expr 的内部定义见[关系结构](../Expr/Expr.md#表达式定义)。固定输入指令序列 \(\mathbf I\) 的谓词域为 \(\mathrm{Predicate}_{\mathbf I}\)，其五类构造见[谓词类型](../Predicate/谓词定义.md#类型与结构相等)。

##### 语义状态

定义

\[
\boxed{\mathrm{State}
:=\mathscr F(\mathrm{Expr})\times\mathscr F(\mathrm{Predicate}_{\mathbf I}),
\qquad \sigma=(\mathcal E,\mathcal P).}
\]

其中 \(\mathcal E\in\mathscr F(\mathrm{Expr})\) 是值绑定与比较约束分量，\(\mathcal P\in\mathscr F(\mathrm{Predicate}_{\mathbf I})\) 是有限观察集合；\(\mathscr F(X)\) 表示 \(X\) 的有限子集集合。\(\mathrm{State}\) 在固定 \(\mathbf I\) 的语境中使用。

\(\mathcal E\) 的内部结构见[表达式定义](../Expr/Expr.md#表达式分量)。\(\mathcal P\) 的五类观察分别为 Helper 的外部调用观察、Branch 的选定方向及其条件、Return 的最外层正常返回结果、MapWrite 的 Map 元素内写入与 PacketWrite 的包写入，各类解释入口见[谓词定义](../Predicate/谓词定义.md#类型与结构相等)。完整路径条件由历史记录中各步的状态解释，见[比较指令处理](Jump/待处理.md#后继状态与历史条件)。

\(\mathrm{Predicate}_{\mathbf I}\) 采用[结构相等](../Predicate/谓词定义.md#类型与结构相等)下的集合语义，不在该分量内部记录重复次数或事件顺序。历史记录保留步骤顺序，但不能仅由观察集合的变化恢复重复事件；需要事件轨迹时还须另行定义，见[观察集合与历史顺序](../Predicate/谓词定义.md#观察集合与历史顺序)。

#### 输出

##### 两种结果

设 \(\operatorname{Step}(\mathbf I,j,\sigma_g)\) 为给定局部规则，结果为以下二者之一：

\[
\operatorname{Reject}(a)
\quad\text{或}\quad
\operatorname{Candidates}\bigl([(d_1,j_1,\sigma_1),
\ldots,(d_c,j_c,\sigma_c)]\bigr).
\]

候选数组有限，\(j_k\in\mathrm{Loc}_{\mathbf I}\)，其中 \(1\le k\le c\)。条件未知时通常保留 Taken、NotTaken 两侧；已确定条件只保留相应侧。Exit 候选表示正常结束，其余候选给出后继位置与局部语义增量；Reject 表示拒绝。空数组仅表示已证明没有可行后继。


输出的三个分量依次是方向、后继指令序号与候选的局部语义增量。条件后继的方向见[选择条件后继方向](#选择条件后继方向)。正常返回的目标见[绑定后继位置](#绑定后继位置)。

\(d_k\in\mathrm{Direction}\) 是第 \(k\) 个候选的方向，方向域及 OK 的含义见[方向与后继](路径.md#方向与后继)；\(j_k\) 是该候选的后继指令序号，正常返回时取 Exit；\(\sigma_k=(E_k,P_k)\) 是该候选的局部语义增量，其中 \(E_k\) 是 Expr 增量，\(P_k\) 是 Predicate 增量。\(\sigma_k\) 不得读作已经组合好的全局状态。与输入状态的组合见[状态变换的组合](#状态变换的组合)。\(\operatorname{Reject}(a)\) 的 \(a\) 记录拒绝原因。

\[
(d_k,j_k,\sigma_k)
\in\mathrm{Direction}\times\mathrm{Loc}_{\mathbf I}
\times\mathrm{State}.
\]

#### 局部规则的假设

**假设 B（局部终止与有效性）。** Step 与各局部合并均结束。成功候选的 Expr 键唯一，位宽正确，非 Exit 目标已绑定到输入位置。

**假设 C（语义覆盖）。** 局部规则不遗漏任何可行后继，且成功候选的值与观察正确。只能排除已证明不可行的方向；条件未知、求解失败与绑定失败不能作为不可行证明。

假设 C 才能支持行为覆盖性。局部规则无定义时拒绝本次处理，不把输入末尾自动解释成正常返回。指令值规则是部分函数。

### 局部规则的合法域

推理处理合法的已解码指令实例。运算、源形式、位宽、立即数、访问子类型和偏移均为给定数学参数；从编码取得参数的方法不属于局部规则。合法域约束与数值公式可计算是不同要求。

#### 参数判断

- 算术与移位：要求运算宽度、立即数扩展和移位范围合法。相应规则见[算术赋值](../Expr/寄存器/真实寄存器.md#算术与位运算赋值)。除法与余数采用[除法与余数规则](../Expr/寄存器/真实寄存器.md#除法与余数赋值)。乘法高半采用[乘法高半规则](../Expr/寄存器/真实寄存器.md#乘法高半赋值)。RV32 运算宽度为 32，普通立即数已扩展为整数，立即数移位量在 0 至 31。eBPF 运算宽度为 32 或 64，立即数为 32 位模式，源项按[立即数构造](../Expr/寄存器/真实寄存器.md#常元赋值)扩展。
- 常元与转换：要求常元槽位及转换宽度合法。常元采用[常元规则](../Expr/寄存器/真实寄存器.md#常元赋值)。移动与符号扩展采用[移动与符号扩展规则](../Expr/寄存器/真实寄存器.md#移动与符号扩展赋值)。字节序转换采用[字节序转换规则](../Expr/寄存器/真实寄存器.md#字节序转换赋值)。MOVSX、END、BSWAP 的宽度限制由对应正文给定。
- 访问：核对访问宽度、访问对象的唯一性、资源有效性及实际所需旧值，使用[检查源项与访问对象](#检查源项与访问对象)。RV32 普通访问宽度为 8、16、32；eBPF 普通访问可为 8、16、32、64，MEMSX 为 8、16、32，原子数值单元为 32 或 64。跨单元访问须另有分段语义。
- 真实目标：按[真实寄存器赋值](../Expr/寄存器/真实寄存器.md#真实寄存器赋值)处理固定与只读身份；eBPF 编号限 0 至 10，r10 不可写。RV32 C.LWSP 的零目标非法。
- 分支与跳转：要求偏移单位、位置对应及调用返回约束合法，采用[绑定后继位置](#绑定后继位置)。RV32 普通指令长度为 4 字节、压缩形式为 2 字节，分支与跳转参数提供完整有符号字节偏移。

#### 压缩形式的附加合法域

C.ADDI、C.LI、C.ANDI 使用已符号扩展的六位立即数；C.LUI 的上位常元构造见[常元赋值](../Expr/寄存器/真实寄存器.md#常元赋值)。C.ADDI16SP 的偏移非零且为 16 的整数倍；C.ADDI4SPN 的偏移非零、非负且为 4 的整数倍。压缩字访问使用完整字节偏移，受限寄存器取 x8 至 x15。保留形式与非法参数不因公式可求值而进入成功规则。

#### 无定义时的处理

参数非法、源等式缺失、访问对象不唯一、访问有效性未确立、部分写入缺少旧值或间接目标未绑定时，拒绝对应推理，不用成功空集或新变元代替缺失语义。除法特殊输入按[数值规则](../Expr/寄存器/真实寄存器.md#除法与余数赋值)得到确定结果，不作为异常拒绝。

异常处理、特权状态与未选定的外部语义须独立定义：RV32 的 ECALL、EBREAK、C.EBREAK、MRET、SRET、WFI、SFENCE.VMA 未给出成功规则；eBPF 的 LDDW 平台变量子类型、旧 LD ABS/IND、CALLX、MAY_GOTO 也未给出相应完整规则。LOAD_ACQ、STORE_REL、STX ATOMIC 只具有各 Expr 正文定义的数值关系，未包含并发与排序观察。

外部 helper 或 BTF CALL 没有通用算术结果；调用前 R0 不能充当返回值。符合现有 32 位分派器调用约定的已绑定 helper 使用[Helper谓词](../Predicate/Helper谓词.md)。其返回结果采用[结果赋值](../Predicate/Helper谓词.md#生成的-expr)。一般 eBPF helper、BTF 调用或其他独立契约仍须给出各自的观察与结果规则；没有对应规则时，不能生成成功的空调用效果。

RV32 普通指令的合法域依据为 [RV32I](https://docs.riscv.org/reference/isa/v20260120/unpriv/rv32.html)。压缩形式的依据为 [C 扩展](https://docs.riscv.org/reference/isa/v20260120/unpriv/c-st-ext.html)。eBPF 的依据为 [BPF ISA](https://docs.kernel.org/bpf/standardization/instruction-set.html)。指令登记见 [IANA 指令登记表](https://www.iana.org/assignments/bpf-instructions/bpf-instructions.xhtml)。Linux BPF 定义见 [Linux BPF 定义](https://github.com/torvalds/linux/blob/master/include/uapi/linux/bpf.h)。LLVM 扩展定义见 [LLVM 扩展定义](https://llvm.googlesource.com/llvm-project/+/17bfc00f7c4a424d7b5dc6da575865833701fd1a%5E%21/)。

### 检查源项与访问对象

检查源项与访问对象要求指令能够取得所需值，且由其操作数与访问规则唯一确定访问对象，不生成替代缺失值的新名称。

1. 参数须满足[指令规则的合法域](#局部规则的合法域)。实际需要的源项和访问对象须满足[局部 Expr 的前提](../Expr/Expr.md#指令结果的前提)。两项均满足时：进入[指令结果生成](#生成指令结果)。
2. 缺少必需源项、位宽不符、资源单元不能唯一确定，或必要访问条件不成立：拒绝本次处理。
3. 访问涉及尚未记录的虚拟寄存器：按[未记录虚拟寄存器的取源](../Expr/Expr.md#未记录虚拟寄存器的取源)判断能否补充。补充成功后继续；无依据时拒绝。

具体需要哪些源项由指令规则规定，见[值规则索引](../Expr/Expr.md#索引)。不要求每个目标都有旧值；需要旧值的情形由[字段读写](../Expr/寄存器/单元字段读写.md#单元字段读写)等规则决定。helper 编号和参数的检查见 [helper Predicate 创建](../Predicate/Helper谓词.md)。

检查源项与访问对象仅检查所选规则的前提，不自动证明访问对象与实际指令操作数一致或完整资源契约成立。

### 生成指令结果

\(\sigma_k=(E_k,P_k)\) 采用与指令及该候选方向对应的关系或观察规则。各候选都从同一个执行前状态 \(\sigma_g\) 取源。

- 普通数值赋值、算术或链接值：使用[真实寄存器值规则](../Expr/寄存器/真实寄存器.md#真实寄存器赋值)。各类数值规则见[数值规则索引](../Expr/寄存器/真实寄存器.md#算术与位运算赋值)。
- 访问对象已确定的资源读写：根据对象类别选择规则。栈采用[栈规则](../Expr/寄存器/虚拟栈.md#虚拟栈读写)。Map 采用[Map 规则](../Expr/寄存器/虚拟映射.md#虚拟映射读写)，元素内写入另按[MapWrite 生成条件](../Predicate/MapWrite谓词.md#生成条件)取得局部观察。包采用[包规则](../Expr/寄存器/包字节.md#包字节读写)，实际存储另按[PacketWrite 生成条件](../Predicate/PacketWrite谓词.md#生成条件)取得局部观察。共享字段函数见[字段读写](../Expr/寄存器/单元字段读写.md#单元字段读写)。
- 访问对象已确定的原子数值操作：使用[原子数值更新与旧值返回](../Expr/寄存器/原子数值更新与旧值返回.md#原子数值更新与旧值返回)，一次取得全部右侧。
- 已识别为 helper 调用的指令实例：调用观察按 [helper Predicate](../Predicate/Helper谓词.md)创建。调用观察建立后，按 [Helper 生成的 Expr](../Predicate/Helper谓词.md#生成的-expr)取得返回赋值与 Map 关联，并保留调用自身的链接效果。
- 条件分支：Expr 的取源和候选规则见[比较指令处理](Jump/待处理.md)。采用这些规则后，进入[条件方向选择](#选择条件后继方向)；各保留候选的 Branch 谓词按[Branch 生成条件](../Predicate/Branch谓词.md#生成条件)生成。
- 无条件跳转或其他所选规则不增加值与观察的操作：保留其控制处理要求，进入[后继位置绑定](#绑定后继位置)。
- 所选局部规则无定义：拒绝本次处理；不能以空效果代替缺失语义。

普通赋值不自动增加观察。空局部观察只表示所选规则没有增加观察，不证明没有副作用。允许的效果组合及局部规则前提见[局部推理接口](#局部推理接口)。多目标取源见[同一执行前状态取源](../Expr/Expr.md#多目标更新与同一来源)。

对于非条件效果，使用 [OK 方向](路径.md#方向与后继)并继续[后继位置绑定](#绑定后继位置)。已识别的最外层正常返回按[Return 生成条件](../Predicate/Return谓词.md#生成条件)生成 Return 谓词；其取源时点与后继结果的一致性由[Return 证明义务](../Predicate/Return谓词.md#证明义务)维护。返回寄存器完整等式的后继检查时点见[准备后继状态](#准备全部后继状态)。缺失时的拒绝处理见[失败情形](#失败情形)。

### 选择条件后继方向

条件后继方向选择仅决定保留哪些方向。源项处理、判定函数及互补 Expr 的构造见[比较 Expr](Jump/待处理.md)。

1. 本次比较判定为真：只保留 Taken 方向。
2. 本次比较判定为假：只保留 NotTaken 方向。
3. 本次比较判定未知：保留 Taken 与 NotTaken 两个方向。

每个保留方向携带其对应的比较 Expr 约束，再进入[后继位置绑定](#绑定后继位置)。目标绑定满足生成前提后，各候选分别按[Branch 生成条件](../Predicate/Branch谓词.md#生成条件)取得自己的 Branch 增量；其接入观察集合见[状态组合的适用范围](#状态变换的组合)。缺失源项属于[前提检查失败](#检查源项与访问对象)，不作为未知比较处理。

条件后继方向选择不利用累积观察求解整条路径的可行性。完整路径条件按[各步的历史状态](Jump/待处理.md#后继状态与历史条件)解释，不把末态约束当成整条路径的条件，也不自动检测或删去不可行路径。

只有已证明没有可行后继时，才允许返回空候选，见[局部推理接口](#局部推理接口)。未知条件、未绑定目标和局部规则无定义均不构成该证明。

### 绑定后继位置

后继位置按内部位置、已识别的最外层返回与未知目标分别处理。

- 普通顺序执行：当 \(j+1\le m\) 时下一指令序号为 \(j+1\)，对应指令 \(\mathbf I[(j+1)-1]\)，绑定该位置；当 \(j=m\) 时缺少下一指令，拒绝，不能自动成为 Exit。
- 直接分支或跳转：使用既定的机器地址与程序位置对应，将目标绑定为 \(j'\in\mathrm{Pos}_{\mathbf I}\)，即 \(1\le j'\le m\)，其指令为 \(\mathbf I[j'-1]\)；索引空间的区别见[程序位置](路径.md#程序位置)。
- 间接跳转：必需源项齐备且目标能够取得唯一绑定时继续；不能确定目标时拒绝。
- 程序内部调用或返回：按既定调用返回绑定保留程序内后继。没有配对或目标语义时拒绝。
- 已识别的最外层正常返回：绑定 Exit，进入[后继状态准备](#准备全部后继状态)。RV32 须到达既定外层返回位置，返回寄存器为 32 位 \(a_0\)；eBPF 外层 EXIT 的返回寄存器为 64 位 \(r_0\)。程序内部返回不采用这个判断。

程序位置采用[指令序列与程序位置](路径.md#指令序列与程序位置)，为从 1 开始的指令序号。RV32 的机器地址 \(\pi\) 与程序位置有既定对应，直接分支或跳转的目标地址为 \(M_{32}(\pi+\delta)\)。JALR 使用旧基址值 a，目标地址为

\[
\tau=2\left\lfloor M_{32}(a+\iota)/2\right\rfloor.
\]

此式清除最低位。目标必须取得唯一位置绑定；链接写入使用[链接值赋值](../Expr/寄存器/真实寄存器.md#跳转链接值赋值)，不能改变目标计算的旧源。压缩直接或间接跳转采用其合法参数，当前位置和实际指令长度由位置对应提供。

eBPF JA、条件跳转和程序内 CALL 采用各自已给定的目标位置绑定，程序内 CALL 还要求调用与返回配对。未定义的参数不能补出位置；其目标不自动产生额外的 PC 等式。

只要求保留方向的目标有效；已由本次确定比较排除的方向不再作为候选。保留两侧时，两侧目标都必须有效。全部绑定完成后进入[准备全部后继状态](#准备全部后继状态)。

### 状态变换的组合

step 为各候选计算局部语义增量。若候选需要补充尚未记录的虚拟寄存器，其组合所用的输入状态由[未记录虚拟寄存器的取源](../Expr/Expr.md#未记录虚拟寄存器的取源)给出。

\(P_k\) 的元素属于[五类谓词域](../Predicate/谓词定义.md#类型与结构相等) \(\mathrm{Predicate}_{\mathbf I}\)。现有 \(\operatorname{mergePredicate}\) 的定义域限于父观察集合与局部观察集合均为 Helper 观察的情形，规则见[结构累积](../Predicate/谓词定义.md#观察集合累积与可满足性)。在该定义域内，调用方将输入状态 \(\sigma_g\) 与候选增量 \(\sigma_k\) 组合为后继状态：

\[
\sigma'=
\bigl(\operatorname{updateExpr}(E_g,E_k),
\operatorname{mergePredicate}(P_g,P_k)\bigr).
\]

**尚待讨论：** 上述组合式暂归调用方应用；操作者没有说明组合发生在哪里，此归属尚未确定。\(\sigma'\) 表示组合后的后继状态，不是 step 返回的 \(\sigma_k\)。

Helper 观察合并满足有限性、单位元、幂等、交换与结合性质，证明见[Predicate 结构累积](../Predicate/谓词定义.md#观察集合累积与可满足性)。合并不判断路径条件是否可满足。Branch、Return、MapWrite、PacketWrite 及混合集合的累积规则与定义域仍由[五类观察累积义务](../Predicate/谓词定义.md#观察集合累积与可满足性)维护；上述组合式不据集合性质自动推广到这些情形。各候选的输入补充和局部变换都从同一个父状态计算，互不使用另一候选的结果。

Expr 的 \(\operatorname{updateExpr}\) 采用[按键覆写](../Expr/Expr.md#关系集合按键覆写)的定义。局部增量的准备与检查见[全部后继状态准备](#准备全部后继状态)；组合的应用归属以上述尚待讨论事项为准。

### 准备全部后继状态

候选类型与有效性前提见[局部推理接口](#局部推理接口)。step 准备并检查各候选的局部语义增量；后继全局状态按[状态变换的组合](#状态变换的组合)构造，应用归属尚待讨论。

1. 对每个候选，从同一个父状态引入所需虚拟寄存器的当前值关系，规则见[未记录虚拟寄存器的取源](../Expr/Expr.md#未记录虚拟寄存器的取源)。引入后的值关系按 [Expr 按键覆写](../Expr/Expr.md#关系集合按键覆写)准备。
2. 对 Exit 候选，在执行前 Expr 分量施加局部值更新后的表达式分量中检查返回寄存器的完整等式：RV32 为 32 位 \(a_0\)，eBPF 为 64 位 \(r_0\)。只有低位关系或不等式不满足要求。返回项可以是符号项；没有返回项则拒绝。右侧可以是尚不能数值求出的符号项，不要求数值求值成功。
3. 各候选的 Helper 局部观察由所属生成规则给出；各条件候选的 Branch 增量、最外层正常返回的 Return 增量、Map 元素内写入的 MapWrite 增量与包写入的 PacketWrite 增量分别由各类生成条件给出。局部观察与输入观察的累积须处于[状态组合的定义域](#状态变换的组合)，混合观察的规则由[观察累积义务](../Predicate/谓词定义.md#观察集合累积与可满足性)维护。运行结果仍从 [Exit 状态的表达式分量 \(\mathcal E\)](#正常返回历史)读取。
4. 任一候选的目标、关系键、位宽或必要观察不满足要求：拒绝整个步骤，不返回已准备的部分候选。
5. 全部候选准备成功：step 返回各候选的方向、后继指令序号与局部语义增量 \(\sigma_k=(E_k,P_k)\)。

状态的两个分量见[语义状态](#语义状态)。不同候选的局部增量都从执行前状态 \(\sigma_g\) 计算，不读取另一个候选的结果。

### 失败情形

- 访问涉及尚未记录的虚拟寄存器，补充无依据时拒绝。
- 间接跳转不能确定目标时拒绝。
- 任一保留候选的目标无定义或不在位置域：拒绝整个步骤。
- Exit 候选的返回寄存器完整等式缺失或位宽不符时拒绝整个步骤。

局部规则无定义时的处理见[局部规则的假设](#局部规则的假设)。

### 正常返回历史

正常返回历史由到达 Exit 的有限执行记录构造。

#### 历史记录类型

固定 \(\mathbf I\) 的历史观察域为 \(\mathrm{Predicate}_{\mathbf I}\)，包含 Helper、Branch、Return、MapWrite 与 PacketWrite，五类含义及解释见[语义状态](#语义状态)。访问有效性与完整外部调用契约仍待证明或定义。

一项历史记录属于 [History 的逐步记录类型](History.md#逐步记录与统一类型) \(\mathrm{Record}_{\mathbf I}\)，保留执行位置、方向、后继位置与有序局部结果。原始指令由该记录的位置在 \(\mathbf I\) 中取得；方向见[方向与后继](路径.md#方向与后继)。

一条历史属于同一所属正文的 \(\mathrm{History}_{\mathbf I}\)，保留入口状态与有限有序记录；成功输出 \(\mathcal H\in\mathscr F(\mathrm{History}_{\mathbf I})\) 为有限历史集合。

序列保留执行顺序，集合不引入顺序。每步的执行后关系与观察由 [History 的 stateAt](History.md#逐步状态与末态)沿既有组合定义域重建；最后一项对应 Exit 状态的表达式分量 \(\mathcal E\) 与五类观察分量。Branch、Return、MapWrite、PacketWrite 及混合集合的累积和记录接入仍受[观察累积义务](../Predicate/谓词定义.md#观察集合累积与可满足性)约束。

Expr 描述中间寄存器关系。比较的两侧可以产生不同 Expr。

#### 历史构造

设正常结束的有限执行记录为[执行前缀 D2](Jump/证明义务-路径合并完备.md#配置执行前缀与后续行为)中的 \(h=(C_0,d_0,\ldots,d_{n-1},C_n)\)，其中 \(C_k=(j_k,\sigma^{(k)})\)，\(j_n=\mathrm{Exit}\)。此处 \(\sigma^{(k)}\) 为该步的完整状态，\(\sigma^{(0)}=\sigma_0\) 为入口状态，第 \(k+1\) 步保留实际准备出的有序局部结果 \(\Lambda_{k+1}\)。其来源与完整性须满足 [H-O1](History.md#控制流与记录来源)，逐次组合须处于 [History 的状态组合定义域](History.md#状态组合的定义域)且产生记录中的后继状态。正常返回历史投影为：

\[
\delta_{k+1}=(j_k,d_k,j_{k+1},\Lambda_{k+1}),
\qquad
\operatorname{hist}(h)=
\operatorname{history}\bigl(\sigma_0,(\delta_1,\ldots,\delta_n)\bigr).
\]

其中 \(0\le k<n\)，\(\delta_{k+1}\in\mathrm{Record}_{\mathbf I}\)；\(\operatorname{history}\) 及其良构定义域见 [History 的统一类型](History.md#逐步记录与统一类型)。\(\operatorname{hist}(h)\in\mathrm{History}_{\mathbf I}\) 只在上述记录来源和组合前提成立时有定义。

最后的 Exit 不产生虚构指令项；它的表达式分量 \(\mathcal E_n\) 已包含在最后一条真实指令的执行后状态中。运行结果从 Exit 状态的 \(\mathcal E_n\) 中读取返回寄存器的完整等式右侧项：RV32 读取 32 位 \(a_0\)，eBPF 读取 64 位 \(r_0\)。该完整等式由[后继状态准备](#准备全部后继状态)检查，缺失时拒绝返回步骤；结果不从 \(\mathcal P_n\) 中读取。
