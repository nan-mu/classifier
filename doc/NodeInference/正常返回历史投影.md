# 正常返回历史投影

本步骤只接收 Complete 图并投影正常返回路径。历史的数学类型和投影在本文维护。

## 判断与处理

- 展开 Complete：枚举根到 Exit 的路径，并按下文投影为有限历史集合。
- 展开 Fail：不将部分图中的历史作为完整输出。
- 叶节点不是 Exit：不将该叶路径视为正常返回历史。

## 历史记录类型

设 \(\mathrm{Predicate}\) 为观察域。返回与 helper 调用观察的类型、解释和累积规则集中定义于[Predicate 文档](../Predicate/谓词阅读索引.md)；访问与完整外部调用契约仍待定义。在比较两种架构的行为前，还需指定观察的选取与对应。

一项历史记录属于

\[
\mathrm{Insn}\times\mathscr F(\mathrm{Predicate})
\times\mathrm{ExprSet}
\times\mathscr F(\mathrm{Inst}_{\mathrm{next}}).
\]

四个分量依次为原始指令、返回与调用观察集合、值绑定与比较约束分量，以及后继信息集合。后继信息见[方向与边](展开图与执行路径.md)。

一条历史是这些记录组成的有限序列，成功输出为有限历史集合：

\[
\boxed{
\mathcal H\in\mathscr F\!\left(
\left(\mathrm{Insn}\times\mathscr F(\mathrm{Predicate})
\times\mathrm{ExprSet}
\times\mathscr F(\mathrm{Inst}_{\mathrm{next}})\right)^\ast
\right).
}
\]

序列保留执行顺序，集合不引入顺序。下文的投影采用每条指令执行后的关系与谓词，因而保留最后一次返回观察；[普通节点](语义状态与节点快照.md)采用执行前快照。

Expr 描述中间寄存器关系。不同架构可以产生不同 Expr；这些中间关系的相等不是跨架构行为等价性的定义。

## 完成图的投影

对 Complete 图定义正常结束引用集合

\[
\mathcal T_G=\{\eta:0\le\eta<|\mathrm{Nodes}|,\
\operatorname{loc}(\mathrm{Nodes}[\eta])=\mathrm{Exit}\}.
\]

设正常结束路径为 \(h=(\eta_0,d_0,\ldots,d_{n-1},\eta_n)\)。第 \(k\) 条边的源位置为 \(j_k\)，目标快照为 \((\mathcal E_{k+1},\mathcal P_{k+1})\)，令

\[
S_k=\bigl(\mathbf I[j_k],\mathcal P_{k+1},\mathcal E_{k+1},
\{(d_k,\eta_{k+1})\}\bigr),
\qquad
\operatorname{hist}(h)=(S_0,\ldots,S_{n-1}).
\]

最后的 Exit 不产生虚构指令项；返回观察已包含在最后一条真实指令的执行后快照中。

**命题 13。**

\[
\mathcal H_G=\{\operatorname{hist}(h):h\text{ 是从 root 到 Exit 的路径}\}
\]

是有限集合。

**证明。** 由[有限性定理 11](有限预算展开的终止证明.md)与[树结构定理 12](展开树结构与快照不变量证明.md)，图有限且为树。每个 Exit 节点有唯一的根路径，故正常结束路径数量至多为节点数，各路径长度也有限。投影保持有限性。\(\square\)

节点引用必须在所属图内解释。非 Exit 的不可行叶不属于正常返回历史；Fail 图中的部分历史也不能作为完整输出。

在[候选契约的假设 C](局部候选类型与前提.md)下，可进一步按路径长度归纳：每条可行的正常结束执行均能逐步对应到候选边；若展开 Complete，则其完整路径出现在 \(\mathcal H_G\) 中。反向对应还要求候选不仅覆盖行为，而且每个候选都有相应行为见证。本文不在局部语义未给定时宣称这一等价成立。
