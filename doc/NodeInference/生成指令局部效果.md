# 生成指令局部效果

本步骤选择对应的关系或观察规则。各候选都从同一个父节点快照取源。

## 判断与处理

- 普通数值赋值、算术或链接值：使用[真实寄存器值规则](../Expr/真实寄存器赋值.md)及其中链接的[各类数值规则](../Expr/表达式阅读索引.md#真实目标与数值函数)。
- 已绑定资源读写：根据对象类别使用[栈](../Expr/虚拟栈读写.md)、[Map](../Expr/虚拟映射读写.md)或[包](../Expr/包字节读写.md)规则。共享字段函数见[字段读写](../Expr/单元字段读写.md)。
- 已绑定原子数值操作：使用[原子数值更新与旧值返回](../Expr/原子数值更新与旧值返回.md)，一次取得全部右侧。
- 已由调用绑定识别为 helper 的调用：先按 [helper Predicate](../Predicate/辅助调用观察.md)创建调用观察，再按 [helper Expr](../Expr/辅助调用结果.md)取得返回赋值与 Map 关联，并保留调用自身的链接效果。
- 条件分支：使用[比较指令处理](比较指令处理.md)的取源和候选规则，进入[条件方向选择](选择条件后继方向.md)。
- 无条件控制转移或其他所选规则不增加值与观察的操作：保留其控制处理要求，进入[后继位置绑定](绑定后继位置.md)。
- 所选局部规则无定义：拒绝本次处理；不能以空效果代替缺失语义。

普通赋值不自动增加观察。空局部观察只表示所选规则没有增加观察，不证明没有副作用。允许的效果组合及局部规则前提见[候选契约](局部候选类型与前提.md)。多目标取源见[同一源快照](../Expr/多目标更新与同一源快照.md)。

对于非条件效果，使用 Only 方向并继续[后继位置绑定](绑定后继位置.md)。正常返回的值观察在确认 Exit 和取得更新后返回项时处理，见[准备后继状态](准备全部后继状态.md)。
