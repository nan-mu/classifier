# 绑定后继位置

本步骤区分内部位置、已识别的最外层返回与未知目标。

## 判断与处理

- 普通顺序执行：下一位置属于[程序位置域](指令序列与程序位置.md)时绑定该位置；缺少下一指令时拒绝，不能自动成为 Exit。
- 直接分支或跳转：使用既定的机器地址与程序位置对应绑定目标。变长指令的字节偏移不能直接作为序列索引。
- 间接跳转：必需源项齐备且目标能够取得唯一绑定时继续；不能确定目标时拒绝。
- 已识别的最外层正常返回：绑定 Exit，并进入[后继状态准备](准备全部后继状态.md)取得更新后的返回观察。程序内部返回不采用这个判断。
- 任一保留候选的目标无定义或不在位置域：拒绝整个步骤，保留当前图。

具体控制目标的数值规则及返回识别条件见 [控制转移与返回识别](控制转移与返回识别.md)。本步骤不重复目标计算公式。

只要求保留方向的目标有效；已由本次确定比较排除的方向不再作为候选。保留两侧时，两侧目标都必须有效。全部绑定完成后进入[准备全部后继状态](准备全部后继状态.md)。
