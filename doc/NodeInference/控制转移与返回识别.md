# 控制转移与返回识别

控制转移确定后继位置，数值赋值与观察分别由 Expr 和 Predicate 规则给出。程序内部目标、外层正常返回及外部调用须分别识别；未知目标不能当作 Exit 或已证明不可行方向。

## 位置与目标

程序位置采用[指令序列与程序位置](指令序列与程序位置.md)。RV32 的机器地址 \(\pi\) 与程序位置有既定对应，直接分支或跳转的目标地址为 \(M_{32}(\pi+\delta)\)。JALR 使用旧基址值 a，目标地址为

\[
\tau=2\left\lfloor M_{32}(a+\iota)/2\right\rfloor.
\]

此式清除最低位。目标必须取得唯一位置绑定；链接写入使用[链接值赋值](../Expr/跳转链接值赋值.md)，不能改变目标计算的旧源。压缩直接或间接跳转采用其合法参数，当前位置和实际指令长度由位置对应提供。

eBPF JA、条件跳转和程序内 CALL 采用各自已给定的目标位置绑定，程序内 CALL 还要求调用与返回配对。这里不从未定义的参数补出位置；其控制转移不自动产生额外 PC 等式。

## 判断与处理

- 条件转移：依据[条件后继选择](选择条件后继方向.md)保留方向，再要求每个保留方向的目标有效。
- 无条件转移：要求唯一有效目标，进入[后继绑定](绑定后继位置.md)。无链接跳转不增加 Expr；有链接跳转另外采用链接赋值规则。
- 程序内部调用或返回：按既定调用返回绑定保留程序内后继。没有配对或目标语义时拒绝。
- 已识别的最外层正常返回：绑定 Exit，在[后继准备](准备全部后继状态.md)中按[返回观察](../Predicate/返回值观察的解释与生成.md)取得结果项。RV32 须到达既定外层返回位置；eBPF 外层 EXIT 观察已有且已定义的 64 位 r0。
- 外部调用：要求独立契约；已绑定 helper 使用[调用 Predicate](../Predicate/辅助调用观察.md)和[返回 Expr](../Expr/辅助调用结果.md)，链接赋值仍须保留。普通链接公式不提供返回结果或 Map 修改。
- 合法 NOP、HINT 或选定观察范围内的空效果：保留有效顺序后继。FENCE、FENCE.TSO 只在不观察内存排序的模型中取空效果，这不证明其完整行为等价于空操作。

条件分支只增加 Expr 比较约束，不赋值。无链接跳转、没有链接赋值的程序内 CALL 和返回观察可以具有空 Expr，仍需完整处理取源、控制和必要观察。未定义规则采用[拒绝处理](指令参数与规则定义域.md)，不自动补成顺序后继。

数值及控制依据为 [RV32I](https://docs.riscv.org/reference/isa/v20260120/unpriv/rv32.html)、[C 扩展](https://docs.riscv.org/reference/isa/v20260120/unpriv/c-st-ext.html)与 [BPF ISA](https://docs.kernel.org/bpf/standardization/instruction-set.html)。
