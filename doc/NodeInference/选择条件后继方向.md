# 选择条件后继方向

本步骤只决定保留哪些方向。源项处理、判定函数及互补 Expr 的构造见[比较 Expr](比较指令处理.md)。

## 判断与处理

1. 本次比较判定为真：只保留 Taken 方向。
2. 本次比较判定为假：只保留 NotTaken 方向。
3. 本次比较判定未知：保留 Taken 与 NotTaken 两个方向。

每个保留方向携带其对应的比较 Expr 约束，再进入[后继位置绑定](绑定后继位置.md)。缺失源项属于[前提检查失败](检查源项与资源绑定.md)，不作为未知比较处理。

本步骤不利用累积观察求解整条路径的可行性。完整路径条件按[历史快照](比较指令处理.md#后继快照与历史条件)解释，不把末态约束当成整条路径的条件，也不自动检测或删去不可行路径。

只有已证明没有可行后继时，才允许返回空候选，见[局部候选契约](局部候选类型与前提.md)。未知条件、未绑定目标和局部规则无定义均不构成该证明。
