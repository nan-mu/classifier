# 路径

## 指令序列与程序位置

机器地址与序列位置的对应作为固定绑定给定。

令原始指令编码宽度集合为 \(W_{\mathrm{Insn}}=\{16,32,64\}\)，定义

\[
\mathrm{Insn}
=\bigsqcup_{w\in W_{\mathrm{Insn}}}
\bigl(\{w\}\times\mathbb B_w\bigr),
\qquad
\mathbf I=(i_0,\ldots,i_{m-1})\in\mathrm{Insn}^\ast.
\]

原始指令携带编码位宽及位模式。其语义解释可使用已解码指令对象；二者不能与序列位置混同。指令编码宽度与寄存器位宽是不同的概念。

### 程序位置

对长度为 \(m\) 的输入定义

\[
\mathrm{Pos}_{\mathbf I}=\{j\in\mathbb N:1\le j\le m\},
\qquad
\mathrm{Loc}_{\mathbf I}=\mathrm{Pos}_{\mathbf I}\sqcup\{\mathrm{Exit}\}.
\]

程序位置 \(j\) 是从 1 开始的指令序号（instruction ordinal），其合法域为 \(\mathrm{Pos}_{\mathbf I}\)，该位置的指令为 \(\mathbf I[j-1]=i_{j-1}\)。机器地址（machine address）标识机器中的指令地址，字节偏移（byte offset）是相对于程序起始地址的字节位移，节点引用（node reference）是外部运行时提供的不透明标识。这四个索引空间彼此不同；变长指令的字节偏移不是其指令序号。Exit 不属于 \(\mathrm{Pos}_{\mathbf I}\)。

Exit 是正常结束标记。未知目标、无定义行为和未完成推理均不能用 Exit 代替。机器地址到序列位置的绑定由局部规则给定。

## 方向与后继

\[
\mathrm{Direction}=\{\mathrm{OK},\mathrm{Taken},\mathrm{NotTaken}\},
\]

OK 表示该指令恰有一个后继方向；Taken、NotTaken 表示条件成立与不成立的方向。
