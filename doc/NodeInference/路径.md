# 路径

## 指令序列与程序位置

机器地址与序列位置的对应作为固定绑定给定。

令原始指令编码宽度集合为 \(W_{\mathrm{Insn}}=\{16,32,64\}\)，定义

\[
\mathrm{Insn}
=\bigsqcup_{w\in W_{\mathrm{Insn}}}
\bigl(\{w\}\times\mathbb B_w\bigr),
\qquad
\mathbf I=(i_0,\ldots,i_{m-1})\in\mathrm{Insn}^\ast.
\]

原始指令携带编码位宽及位模式。其语义解释可使用已解码指令对象；二者不能与序列位置混同。指令编码宽度与寄存器位宽是不同的概念。

### 程序位置

对长度为 \(m\) 的输入定义

\[
\mathrm{Pos}_{\mathbf I}=\{j\in\mathbb N:1\le j\le m\},
\qquad
\mathrm{Loc}_{\mathbf I}=\mathrm{Pos}_{\mathbf I}\sqcup\{\mathrm{Exit}\}.
\]

程序位置 \(j\) 是从 1 开始的指令序号（instruction ordinal），其合法域为 \(\mathrm{Pos}_{\mathbf I}\)，该位置的指令为 \(\mathbf I[j-1]=i_{j-1}\)。机器地址（machine address）标识机器中的指令地址，字节偏移（byte offset）是相对于程序起始地址的字节位移，节点引用（node reference）按创建顺序从 0 编号，从 \(\mathrm{root}=0\) 开始。这四个索引空间彼此不同；变长指令的字节偏移不是其指令序号。Exit 不属于 \(\mathrm{Pos}_{\mathbf I}\)。

Exit 是正常结束标记。未知目标、无定义行为和未完成推理均不能用 Exit 代替。机器地址到序列位置的绑定由局部规则给定。

## 方向与后继

\[
\mathrm{Direction}=\{\mathrm{Only},\mathrm{Taken},\mathrm{NotTaken}\},
\qquad
\mathrm{Inst}_{\mathrm{next}}=\mathrm{Direction}\times\mathrm{NodeId}.
\]

Only 表示唯一后继；Taken、NotTaken 表示条件成立与不成立的方向。

当前构造为到达同一程序位置的两侧分别保留方向及状态；是否及如何合并同位置到达见[step 的开放问题](step.md#同位置到达的共享问题)。

## 展开图、节点与边

节点内容见[语义状态与节点状态](step.md#语义状态与节点状态)。有限展开图为

\[
G=(\mathrm{Nodes},\mathrm{Edges},\mathrm{root}),
\qquad\mathrm{root}=0.
\]

Nodes 是按创建顺序编号的有限节点序列。连接为 \((\eta,d,\zeta)\)。

同位置的不同到达如何建立节点，以及新节点与连接的建立规则见[节点追加](step.md#追加节点与调度工作)。

当前构造在每次到达时创建新节点，边总由已有引用指向新引用。各条到达共享已经形成的执行前缀；当前构造保留分别到达的后缀，是否及如何合并见[step 的开放问题](step.md#同位置到达的共享问题)。程序连接图可以有环，展开图则逐次记录循环到达。

## 路径

路径为

\[
h=(\eta_0,d_0,\eta_1,\ldots,d_{n-1},\eta_n),
\qquad
(\eta_k,d_k,\eta_{k+1})\in\mathrm{Edges}.
\]

空路径只包含一个节点。正常结束路径从 root 到 Exit。
