# 有界循环的节点展开例证

本文用一个有界循环说明队列、节点引用与预算的关系，不重写 Expr 或 Predicate 的内部规则。

取 \(w=32\)，给定入口等式 \(r=C_w(0)\)，考虑四个位置：位置 0 判断 \(r\ge_u C_w(3)\)，成立时到 3，否则到 1；位置 1 令 \(r\leftarrow\mathrm{ADD}_w^\star(r,C_w(1))\) 后到 2；位置 2 到 0；位置 3 正常返回并观察 \(r\)。此处右侧的 \(r\) 表示从执行前等式取得的项，分支按[比较指令处理](比较指令处理.md)加入各自的 Expr 约束，返回采用[返回观察](../Predicate/返回值观察的解释与生成.md)。

这些 32 位常元的加法不发生回绕。四次判断分别读取常元 0、1、2、3；前三次走 NotTaken，第四次走 Taken。

若每次到达都按创建顺序编号，判断节点引用为 0、3、6、9，位置 3 的引用为 10，Exit 的引用为 11。Step 次数为

\[
4\text{ 次判断}+3\text{ 次加法}+3\text{ 次跳转}+1\text{ 次返回}=11.
\]

故 \(B=11\) 时完成，\(B=10\) 时返回位置尚未展开。重复的程序位置对应不同快照节点，既保留逐轮状态，又满足展开图无环。

预算耗尽且待展开序列非空时，结果为 LimitExceeded；局部规则无定义或合并失败则产生相应的 Fail。二者都不构成程序不终止的证明。循环摘要与含星号的路径表达式另见 [代数程序分析](路径语言与位置消去.md)；它们需要独立的语义与证明。
