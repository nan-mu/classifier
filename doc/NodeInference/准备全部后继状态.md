# 准备全部后继状态

本步骤准备候选状态，不创建节点或边。候选类型与有效性前提见[局部候选契约](局部候选类型与前提.md)。

## 判断与处理

1. 对每个候选，从同一个父快照按[虚拟输入单元引入](../Expr/虚拟输入单元引入.md)与 [Expr 按键覆写](../Expr/关系集合按键覆写.md)准备值关系。
2. 对 Exit 候选，在局部值更新后按[返回 Predicate](../Predicate/返回值观察的解释与生成.md)取得返回观察。返回项可以是符号项；没有返回项则拒绝。
3. 按 [Predicate 结构累积](../Predicate/观察集合累积与可满足性.md)准备候选的观察集合，包括相应的返回观察。
4. 任一候选的目标、关系键、位宽或必要观察不满足要求：拒绝整个步骤，保留当前图，不追加已准备的部分候选。
5. 全部候选准备成功：进入[追加节点与调度](追加节点与调度工作.md)。

状态的两个分量及快照含义见[语义状态](语义状态与节点快照.md)。不同候选不读取另一个候选的结果，也不在共同程序位置合并状态。Expr 与 Predicate 的处理公式由所链接的文章维护。
