# 指令参数与规则定义域

推理处理合法的已解码指令实例。运算、源形式、位宽、立即数、访问子类型和偏移均为给定数学参数；本文件不定义从编码取得参数的方法。合法域约束与数值公式可计算是不同要求。

## 参数判断

- 算术与移位：核对运算宽度、立即数扩展和移位范围，再采用[算术赋值](../Expr/算术与位运算赋值.md)、[除法与余数](../Expr/除法与余数赋值.md)或[乘法高半](../Expr/乘法高半赋值.md)。RV32 运算宽度为 32，普通立即数已扩展为整数，立即数移位量在 0 至 31。eBPF 运算宽度为 32 或 64，立即数为 32 位模式，源项按[立即数构造](../Expr/常元赋值.md)扩展。
- 常元与转换：核对常元槽位及转换宽度，再采用[常元](../Expr/常元赋值.md)、[移动与符号扩展](../Expr/移动与符号扩展赋值.md)或[字节序转换](../Expr/字节序转换赋值.md)。MOVSX、END、BSWAP 的宽度限制由对应正文给定。
- 访问：核对访问宽度、唯一绑定、资源有效性及实际所需旧值，使用[源项与资源检查](检查源项与资源绑定.md)。RV32 普通访问宽度为 8、16、32；eBPF 普通访问可为 8、16、32、64，MEMSX 为 8、16、32，原子数值单元为 32 或 64。跨单元访问须另有分段语义。
- 真实目标：按[真实寄存器赋值](../Expr/真实寄存器赋值.md)处理固定与只读身份；eBPF 编号限 0 至 10，r10 不可写。RV32 C.LWSP 的零目标非法。
- 控制转移：核对偏移单位、位置对应及调用返回约束，再采用[控制转移与返回识别](控制转移与返回识别.md)。RV32 普通指令长度为 4 字节、压缩形式为 2 字节，分支与跳转参数提供完整有符号字节偏移。

## 压缩形式的附加合法域

C.ADDI、C.LI、C.ANDI 使用已符号扩展的六位立即数；C.LUI 的上位常元构造见[常元赋值](../Expr/常元赋值.md)。C.ADDI16SP 的偏移非零且为 16 的整数倍；C.ADDI4SPN 的偏移非零、非负且为 4 的整数倍。压缩字访问使用完整字节偏移，受限寄存器取 x8 至 x15。保留形式与非法参数不因公式可求值而进入成功规则。

## 无定义时的处理

参数非法、源等式缺失、资源绑定不唯一、访问有效性未确立、部分写入缺少旧值或间接目标未绑定时，拒绝对应推理，不用成功空集或新变元代替缺失语义。除法特殊输入按[数值规则](../Expr/除法与余数赋值.md)得到确定结果，不作为异常拒绝。

异常处理、特权状态与未选定的外部语义须独立定义：RV32 的 ECALL、EBREAK、C.EBREAK、MRET、SRET、WFI、SFENCE.VMA 未给出成功规则；eBPF 的 LDDW 平台变量子类型、旧 LD ABS/IND、CALLX、MAY_GOTO 也未给出相应完整规则。LOAD_ACQ、STORE_REL、STX ATOMIC 只具有各 Expr 正文定义的数值投影，未包含并发与排序观察。

外部 helper 或 BTF CALL 没有通用算术结果；调用前 R0 不能充当返回值。符合现有 32 位分派器调用约定的已绑定 helper 使用[调用观察](../Predicate/辅助调用观察.md)与[结果赋值](../Expr/辅助调用结果.md)。一般 eBPF helper、BTF 调用或其他独立契约仍须给出各自的观察与结果规则；没有对应规则时，不能生成成功的空调用效果。

合法域依据为 [RV32I](https://docs.riscv.org/reference/isa/v20260120/unpriv/rv32.html)、[C 扩展](https://docs.riscv.org/reference/isa/v20260120/unpriv/c-st-ext.html)、[BPF ISA](https://docs.kernel.org/bpf/standardization/instruction-set.html)、[IANA 指令登记表](https://www.iana.org/assignments/bpf-instructions/bpf-instructions.xhtml)、[Linux BPF 定义](https://github.com/torvalds/linux/blob/master/include/uapi/linux/bpf.h)与 [LLVM 扩展定义](https://llvm.googlesource.com/llvm-project/+/17bfc00f7c4a424d7b5dc6da575865833701fd1a%5E%21/)。
