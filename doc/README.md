## 比较问题

比较使用与赋值相同的 Expr 结构。分支把各自约束加入新节点，完整值绑定保持不变；后续赋值覆盖目标寄存器的全部旧关系。旧节点不变，因此完整路径条件从历史快照读取，而非保存在比较 Predicate 或仅由末态约束恢复。

- [Expr 的比较关系](Expr/比较关系.md)：值与约束角色、符号含义、解释、部分判定和补关系。
- [节点的比较指令处理](NodeInference/比较指令处理.md)：RV32/eBPF 取源、各指令两侧 Expr、方向选择及历史保存。

## 证明之间的依赖

符号项的类型与纯数值全函数假设给出闭项求值的良定义性。solve 的解释保持性随后支撑指令符号值与数值公式的一致性。值绑定唯一性与严格覆写性质支撑初态、局部效果和状态更新的结构有效性。

局部处理终止及有限候选假设支撑有预算展开的终止与有限性。每次到达新建节点的定义给出树结构，再推出正常返回历史集合有限。这些结构结论本身不证明局部效果符合真实指令语义。

路径消去证明针对图上的全部有限路径。将其解释为实际行为，需要边关系、条件测试与调用返回配对的语义对应；使用近似摘要时还需独立证明摘要可靠。

## 当前证明边界

以下结论已经在本文档体系中给出定义层面的证明：

- 在纯数值子域及相应假设下，闭项求值良定义，solve 幂等且保持项与单个 Expr 的解释。
- 按寄存器严格覆写保持值绑定唯一，并满足空更新、重复更新与结合性质。
- 32/64 位比较 Expr 的指令生成规则、互补方向划分、历史快照保存比较条件、返回与调用观察结构累积的集合性质，以及同快照互补条件的真值划分。
- 指令数值投影的位宽闭合、低位覆盖及多目标旧值读取性质。
- 四类寄存器的身份区分、Stack/Map 字段覆盖、包字节拼接与重叠一致，以及分类规则的有限性与键唯一性。
- 指定 RV32 初态 Expr 的有限性、键唯一性与代数可满足性。
- 在局部处理终止、候选有限且入口有效的假设下，有限预算展开结束，完成图的正常返回历史有限。
- 有限图的位置消去保持路径语言，循环语言方程具有所给最小解。

以下问题仍需定义或证明：

- 访问与七种 helper 以外的调用观察、完整 helper 契约、事件顺序与重复，以及扩展观察的解释和合并规则。
- 地址向虚拟单元归约的正确性、跨单元一致性及访问有效性的证明。[Expr 分类前提](Expr/指令局部效果的前提.md)将唯一绑定和有效访问列为前提，不自动证明具体访问满足它们。
- 外部调用结果、寄存器变化与调用返回配对。
- 两种指令集的入口对应、观察对应与完整行为等价性。
- 任意循环摘要的可靠性，以及有限退出以外的观察语义。
