# 数学文档索引

本目录面向论文读者，集中给出符号值、寄存器关系、Predicate 观察、入口条件、有限执行历史与代数路径分析的定义、推导和证明。文档中的「定义」「假设」「命题」分别表示模型选择、必要前提与可推导结论。

## 阅读次序

1. [共同数学基础](common-math.md)第 1—2 节给出位向量与输入；接着读[寄存器文档](registers.md)第 1 节的四类身份。再读共同数学第 4—8 节的 Term、Expr 与 solve，以及第 10、12 节的解释保持及覆写性质。最后读寄存器文档第 2—8 节的指令分类、四类 Expr 规则、多目标更新及引理。
2. [RV32IMC 值函数](rv32imc-expr-value-functions.md)与 [eBPF 值函数](ebpf-expr-value-functions.md)：在相同共同对象上分别定义两种指令集的数值效果，并给出局部正确性命题。
3. [RV32 入口关系](rv32-initial-expr.zh.md)：构造初态，证明有限性、同位宽、键唯一性及 Expr 的代数相容性。
4. [Predicate 文档](predicates.md)：集中定义比较、返回与 helper 调用观察、指令生成规则和结构累积，并给出 helper 返回 Expr 与 lookup 关联规则。证明互补方向、源项固定及合并性质，并区分累积与路径可行性。
5. 回到[共同数学基础](common-math.md)第 13—18 节：建立快照节点与有限展开，证明终止、树结构和历史投影的有限性。
6. [代数程序分析](algebraic-program-analysis.zh.md)：研究含循环程序图的路径语言，证明位置消去、最小解及行为关系解释，并与有限展开比较。

## 证明之间的依赖

符号项的类型与纯数值全函数假设给出闭项求值的良定义性。solve 的解释保持性随后支撑指令符号值与数值公式的一致性。关系键唯一性与覆写性质支撑初态、局部效果和状态更新的结构有效性。

局部处理终止及有限候选假设支撑有预算展开的终止与有限性。每次到达新建节点的定义给出树结构，再推出正常返回历史集合有限。这些结构结论本身不证明局部效果符合真实指令语义。

路径消去证明针对图上的全部有限路径。将其解释为实际行为，需要边关系、条件测试与调用返回配对的语义对应；使用近似摘要时还需独立证明摘要可靠。

## 当前证明边界

以下结论已经在本文档体系中给出定义层面的证明：

- 闭项求值良定义，solve 幂等且保持项与单个 Expr 的解释。
- 按键覆写保持键唯一，并满足空更新、重复更新与结合性质。
- 比较观察的互补方向划分、源项固定、结构累积的集合性质，以及同源互补条件的不可满足性。
- 指令数值投影的位宽闭合、低位覆盖及多目标旧值读取性质。
- 四类寄存器的身份区分、Stack/Map 字段覆盖、包字节拼接与重叠一致，以及分类规则的有限性与键唯一性。
- 指定 RV32 初态 Expr 的有限性、键唯一性与代数可满足性。
- 在局部处理终止、候选有限且入口有效的假设下，有限预算展开结束，完成图的正常返回历史有限。
- 有限图的位置消去保持路径语言，循环语言方程具有所给最小解。

以下问题仍需定义或证明：

- 访问与七种 helper 以外的调用观察、完整 helper 契约、64 位比较观察、事件顺序与重复，以及扩展观察的解释和合并规则。
- 地址向虚拟单元归约的正确性、跨单元一致性及访问有效性的证明。寄存器文档将唯一绑定和有效访问列为分类前提，不自动证明具体访问满足它们。
- 外部调用结果、寄存器变化与调用返回配对。
- 两种指令集的入口对应、观察对应与完整行为等价性。
- 任意循环摘要的可靠性，以及有限退出以外的观察语义。

## 记号约定

寄存器 Reg 的定义集中在寄存器文档中维护；Predicate 的定义集中在 Predicate 文档中维护。原始指令 Insn、符号项 Term 与关系 Expr 的共同定义集中在共同数学文档中维护。指令集文档使用其位宽与符号提升记号；初态文档只增加入口假设；代数文档中的加、乘和星号表示路径或行为组合。

集合并集、顺序组合、寄存器覆写和观察合并具有不同定义，不能因符号相近而互换。未定义、已证明不可行、正常返回与预算不足也分别保留其数学含义。
