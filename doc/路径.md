# 路径

路径把 `create`、`step` 和 `update` 连起来，保留观察的顺序，并用本架构的路径条件限制输入。两端机器指令不需要逐条对应。

普通路径上，每次 `step` 之前留下当前位置和指令前状态。得到结果后记下这一步的方向、表达式和观察，再用 `update` 进入后继。后继是终结标记时，结束这条路径，并保留这一步的 Return 观察。结果是失败时，拒绝当前程序的分析。

两个后继从同一个 \(\sigma_g\) 分别 `update`。两次更新互不影响。验证器先沿一个后继走完，再恢复另一个。待分析的路径都结束，这次分析才完成。

后继位置已经在当前活动路径上出现时，包括回到当前点的自环，把这条边记为回边。只在别的路径上见过的汇合点不算循环。第一次回返时记下回边并停止这个方向，不再为下一轮调用 `step`。这个停止不依赖差异检查的结果。已经发现的出口、跳过循环的路径，以及其他保存的分支，仍继续分析。没有在首轮出现的出口，不根据首轮记录补出来。

**引理 1（History 差异覆盖）** 设 \(\sigma\) 与 \(\tau\) 是同一架构、同一程序、同一指令位置上的初访状态和首轮回返状态，并且每个已定义位恰有一个绑定。\(\Delta_{\mathrm{Reg}}(\sigma,\tau)\) 收集按资源和位区间对齐后、只有一侧有定义或两侧项结构不同的位。\(H\) 是 `history` 返回的区间所覆盖的、带资源身份的位。那么 \(\sigma\) 与 \(\tau\) 在 \(H\) 之外的定义位相同、对应项的结构也相同，当且仅当

\[
\Delta_{\mathrm{Reg}}(\sigma,\tau)\subseteq H.
\]

证明只使用差集的定义：差集含于 \(H\)，就是 \(H\) 外面没有这两类差异。

循环区域里，首轮观察的类别、数量和顺序参加路径匹配。参数保留，但不做严格的表达式匹配。带这条回边截断的程序对，整体至多是弱匹配。首轮相同不能推出后面每一轮的观察仍然相同，也不能推出循环一定终止。
