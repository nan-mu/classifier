# 表达式

表达式记录内部计算的值和约束，给观察提供参数和条件。它本身不是比较目标。两端的表达式状态可以不同。

**定义（表达式）** 一条表达式是

\[
\mathrm{Reg}\;\mathrm{OP}\;\mathrm{Term}.
\]

代码里的字段是 `reg`、`rel`、`term`。寄存器和右侧项使用同一位宽 \(w\)。\(w\) 是这一段位的实际位数，不预设机器字宽。

关系 \(\mathrm{OP}\) 包括相等、不等、无符号与有符号的大小比较，以及位测试。下标 \(q\) 表示取低 \(q\) 位再比较，\(1\le q\le w\)。`bitsnz`\(_q\) 与 `bitsz`\(_q\) 判断这两端低 \(q\) 位按位与的结果是否非零、是否为零。相等既可能是给寄存器的值绑定，也可能是分支上的约束。分支里的等号不给寄存器赋值。

**定义（项）** 项是

\[
\operatorname{Const}_w(c)
\mid
\operatorname{Sym}_w(x)
\mid
f(\mathrm{Term}_1,\ldots,\mathrm{Term}_n).
\]

\(0\le c<2^w\)。\(f\) 是截取、拼接或算术。截取片段的位宽是它实际占的位数。加法、乘法、扩展和切片都写在项里面，不写进 \(\mathrm{OP}\)。

代码里的项还有带展开事件的 `regVar`，以及 `externalResult`。事件号区分同一次推演里的不同节点。它不是 Figure 1 里的变元。表达式匹配在后文规定的前提下可以不把它当作返回值的一部分。

同一资源上，已定义的位区间互不相交。每个已定义位只有一个项。写入只替换被覆盖的区间：原绑定撤掉以后，没被盖住的旧位仍由旧项的对应片段给出。读取一段还没有项的位，这次读取就没有定义。

`solve` 只折叠已经闭合的项，并在允许的代数脊上改写。变元保持为变元。它不把状态里的一条等式代进另一条表达式。因此，即使某处有 \(v_{32}{:}5=128\)，表达式匹配也不会去读它。引理 2 说明，在良构和外部解释全定义的前提下，`solve` 保持项的解释。这个保持不覆盖后文那些只在一对分支上做的写法识别。
