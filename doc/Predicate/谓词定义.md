# 谓词定义

比较关系见[Expr 比较关系](../Expr/待处理.md#比较关系)。比较与后继约束的节点处理见[节点比较处理](../NodeInference/Jump/待处理.md)。

## 类型与结构相等

固定指令序列 \(\mathbf I\)，其谓词域为五类谓词的不交并：

\[
\mathrm{Predicate}_{\mathbf I}
:=\mathrm{Helper}\sqcup\mathrm{Branch}_{\mathbf I}\sqcup\mathrm{Return}\sqcup\mathrm{MapWrite}\sqcup\mathrm{PacketWrite}.
\]

其中 \(\sqcup\) 保留 Helper、Branch、Return、MapWrite 与 PacketWrite 的类别标签。五类的构造分别由[Helper谓词](Helper谓词.md#类型定义)、[Branch谓词](Branch谓词.md#类型定义)、[Return谓词](Return谓词.md#类型定义)、[MapWrite谓词](MapWrite谓词.md#类型定义)与[PacketWrite谓词](PacketWrite谓词.md#类型定义)维护。

Helper 包含 MapLookup、MapUpdate、MapDelete 与 OtherHelper，Map 构造保存冻结字节数组，OtherHelper 保存 32 位参数项向量。\(\mathrm{Branch}_{\mathbf I}\) 的位置分量属于该指令序列的合法位置域，条件保留项位宽标签。\(\mathrm{Return}\) 保留 32 位或 64 位返回项的位宽标签。MapWrite 保留 Map 项与源项位宽及键长度标签；PacketWrite 保留源项位宽标签。改变 \(\mathbf I\) 会改变 Branch 的位置域，因此谓词域是以 \(\mathbf I\) 为索引的类型族；无索引的 \(\mathrm{Predicate}\) 只在固定 \(\mathbf I\) 的语境中作为 \(\mathrm{Predicate}_{\mathbf I}\) 的简称，不能据此直接比较不同程序的位置标记。

同一 \(\mathrm{Predicate}_{\mathbf I}\) 中的两个元素结构相等，当且仅当类别相同且该类的构造分量分别结构相等：

- Helper：子类标签与调用事件身份相同；MapLookup、MapDelete 的 Map 项与冻结键数组分别相同，MapUpdate 还比较冻结值数组与 flags 项，OtherHelper 比较 helper 类型与参数向量。数组长度和顺序均参与比较。
- Branch：条件指令位置、方向及条件分别相同；条件的位宽标签、两端项与关系符均参与比较，关系符保留比较宽度。
- Return：返回项的位宽标签与项结构分别相同。
- MapWrite：Map 项位宽、源项位宽、键长度标签及写入事件身份、Map 项、完整键数组、元素内起始偏移、源项分别相同。
- PacketWrite：写入事件身份、包资源身份、起始偏移、源项位宽与源项结构分别相同。

各类所含项的位宽、运算符、参数与变元身份仍参与结构比较。有限观察集合仍按这种相等去重，不以逻辑等价为商关系。调用身份、helper 类型与参数向量的判据用于 OtherHelper。

一项观察是一个 \(p\in\mathrm{Predicate}_{\mathbf I}\)，分别记录 helper 调用、选定方向的分支条件、最外层正常返回结果、Map 元素内写入或包写入。其解释分别见[Helper 各构造的事件解释](Helper谓词.md#类型定义)、[Branch 的条件与谓词解释](Branch谓词.md#条件与谓词的解释)、[Return 的返回结果解释](Return谓词.md#返回结果的解释)、[MapWrite 的写入事件解释](MapWrite谓词.md#写入事件的解释)与[PacketWrite 的写入事件解释](PacketWrite谓词.md#写入事件的解释)。MapWrite 解释还显式接收写入位宽与字节序；这些输入的适用域由其所属正文维护。跨位宽返回结果的比较见[返回值对应](Return谓词.md#跨架构返回值比较)。

状态观察分量的类型为 \(\mathcal P\in\mathscr F(\mathrm{Predicate}_{\mathbf I})\)，其中 \(\mathscr F(X)\) 为 \(X\) 的有限子集集合。step 执行前的谓词集合为 \(P_g\)，执行前的 Expr 关系为 \(E_g\)，新增的局部谓词集合为 \(\mathcal P_i\)。create 的入口状态构造见[初态接口](../NodeInference/create.md)。

现有 [step 的状态组合与后继准备](../NodeInference/step.md#准备全部后继状态)只规定 Helper 观察的累积；条件分支保留 Expr 比较约束，正常返回检查 Exit 的完整返回项。Branch、Return、MapWrite 与 PacketWrite 的局部增量分别由各类的生成条件维护，其接入 step 的义务见[累积规则的适用范围](#观察集合累积与可满足性)。

## 观察集合累积与可满足性

以下 \(\operatorname{mergePredicate}\)、命题 P2 与 P3 及可满足性边界的既有前提均限于 Helper 观察。有限集合的并集性质本身适用于任意固定元素域，但尚未规定 Branch、Return、MapWrite、PacketWrite 与混合集合作为 step 观察时的累积规则，不能仅凭这些集合性质将现有规则推广到五类谓词。

**义务（Branch、Return、MapWrite 与 PacketWrite 的观察累积）。** 为 \(\mathrm{Predicate}_{\mathbf I}\) 的混合观察集合规定累积规则及其定义域，并证明所采用规则的有限性与相应累积性质。将各方向的 Branch 增量、正常返回的 Return 增量、MapWrite 与 PacketWrite 的写入增量接入 step 的后继准备与历史记录，统一入口观察的合法域，并证明累积和记录保持各类解释及所需的历史信息。MapWrite 解释所需的写入位宽、字节序与记录的联系也须建立。Return 构造的取源时点与现有 Exit 检查时点的一致性由[Return 的源项与后继一致性义务](Return谓词.md#证明义务)维护。

### 结构并集

执行前谓词集合 \(P_g\) 与本步骤的局部集合 \(\mathcal P_i\) 均为有限Helper谓词集合，其合并为

\[
\boxed{\operatorname{mergePredicate}(P_g,\mathcal P_i)
:=P_g\cup\mathcal P_i.}
\]

同一Helper谓词重复出现时只保留一次；不同次 helper 调用的区分见[Helper谓词](Helper谓词.md#数学性质)。

局部状态的组合更新与分支候选的处理见[准备全部后继状态](../NodeInference/step.md)。Expr 的更新见[关系集合按键覆写](../Expr/待处理.md#关系集合按键覆写)。

**命题 P2（有限性与累积性质）。** 若 \(\mathcal P,\mathcal Q,\mathcal R\) 为有限Helper谓词集合，则它们的合并仍有限。

有限Helper谓词集合 \(\mathcal P,\mathcal Q,\mathcal R\) 满足以下包含与并集性质：

\[
\begin{gathered}
\mathcal P\subseteq\mathcal P\cup\mathcal Q,
\qquad \mathcal P\cup\varnothing=\mathcal P,
\qquad \mathcal P\cup\mathcal P=\mathcal P,\\
\mathcal P\cup\mathcal Q=\mathcal Q\cup\mathcal P,
\qquad (\mathcal P\cup\mathcal Q)\cup\mathcal R
=\mathcal P\cup(\mathcal Q\cup\mathcal R).
\end{gathered}
\]

**证明。** 合并元素来自两个有限集合。对任一Helper谓词 \(p\)，其属于合并结果当且仅当属于任一输入集合；逐式展开成员关系即可得到包含、单位元、幂等、交换与结合性质。\(\square\)

这些结论针对有限集合。顺序表示的排列相等须另行规定。完整指令更新的可交换性须另行证明。

### 已取得的源项不随寄存器覆写改变

**命题 P3（源项固定）。** 若 Helper 谓词已由调用时取得的参数项与所需冻结字节数组构成，则之后覆写取得这些项的寄存器或缓冲区不会改变此谓词及其在同一[赋值与解释补全](Helper谓词.md#解释参数) \((\nu,\theta)\) 下的解释。

**证明。** Helper 谓词包含构造时取得的有限项，Map 构造的字节数组按位置保存这些项。状态更新只替换 Expr 键并向 helper 观察集合加入元素，不修改旧项、子类标签或调用身份。OtherHelper 的类型与参数向量、Map 构造的 Map 项、键和值数组及 flags 因此均保持不变；固定赋值下的解释随之保持，字节冻结性质见[Helper 命题 H4](Helper谓词.md#数学性质)。\(\square\)

两次读取同一寄存器可以取得不同项。

### 累积不等于可行性求解

helper 的解释见[Helper 各构造的解释](Helper谓词.md#类型定义)。完整路径条件的解释见[比较指令处理](../NodeInference/Jump/待处理.md)。helper 观察集合的累积既不证明路径可满足，也不检测或删除不可行路径。

## 观察集合与历史顺序

调用次序及逐次状态由执行路径表达。事件顺序不属于观察集合的分量。

设同一路径上的两次 OtherHelper 调用具有不同身份 \(\varepsilon_1\ne\varepsilon_2\)，但 helper 标识 \(h\in H_{\mathrm{other}}\) 与已固定的实参序列 \(\vec t\) 相同；\(H_{\mathrm{other}}\) 的定义见[OtherHelper](OtherHelper谓词.md#类型定义)。最终观察集合 \(\mathcal P\) 为

\[
\mathcal P=\{
\operatorname{helper}(\varepsilon_1,h,\vec t),
\operatorname{helper}(\varepsilon_2,h,\vec t)
\}.
\]

两次调用的区分与累积见[Helper谓词](Helper谓词.md#数学性质)。

相同 \(\operatorname{helper}(\varepsilon,h,\vec t)\) 的累积规则见[结构并集](#结构并集)。若观察访问顺序或逐次输出，则须定义相应事件与观察序列。

比较的路径顺序与旧状态保存见[比较指令处理](../NodeInference/Jump/待处理.md)。当前关系的赋值覆写见[关系集合按键覆写](../Expr/待处理.md#赋值覆盖全部旧关系)。
