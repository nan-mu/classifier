## 后续定义与证明边界

helper 的生成见[Helper谓词](Helper谓词.md)。运行结果的读取见[正常返回历史投影](../NodeInference/推理过程.md#正常返回历史投影)。源项固定与结构累积见[观察集合累积与可满足性](观察集合累积与可满足性.md)。比较的 Expr 关系见[Expr 比较关系](../Expr/比较关系.md)。比较的节点处理见[节点比较处理](../NodeInference/Jump/待处理.md)。返回 Expr 另见 [helper 的 Expr](../Expr/辅助调用结果.md)。以下问题仍须另行设计或证明：

- Stack、Map 与 Packet 访问应观察哪些资源身份、范围、权限与对齐条件，以及访问有效性如何与分类前提联系。
- 各 helper 的具体返回契约、资源变化与调用安全性，以及七种类型以外的外部调用谓词。
- 在累积条件下判定可行性、检测矛盾及约束推理的可靠性。
- 除 helper 调用身份以外的事件身份、完整轨迹和顺序观察规则。
- 跨指令集的输入、返回位宽与其他观察对应。

扩展观察域时，须同时给出新观察的解释、生成规则与合并规则。[结构累积](观察集合累积与可满足性.md)的集合性质不能代替这些定义；现有局部命题也不能直接推出资源访问正确或完整行为等价。
