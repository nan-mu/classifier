# 观察集合与历史顺序

观察集合记录返回与 helper 调用。它不单独保存事件顺序；调用次序及逐次快照由执行路径表达。

设同一路径上的两次 helper 调用具有不同身份 \(\varepsilon_1\ne\varepsilon_2\)，但 helper 标识 h 与已固定的实参序列 \(\vec t\) 相同，随后返回项 u。最终观察集合为

\[
\mathcal P=\{
\operatorname{helper}(\varepsilon_1,h,\vec t),
\operatorname{helper}(\varepsilon_2,h,\vec t),
\operatorname{ret}(u)
\}.
\]

两次调用按身份区分，因此集合累积不会把它们合并；集合本身仍不能判定哪次先发生。调用身份的含义见[辅助调用观察](辅助调用观察.md)。

返回观察不带独立事件身份。重复产生相同 \(\operatorname{ret}(u)\) 时，集合不发生变化，不能仅由相邻观察集合差恢复重复事件。访问顺序或逐次输出还须定义相应事件与观察序列。

比较属于 Expr。后续赋值可清除当前寄存器的旧比较，而已经产生的节点快照保留当次值绑定及比较约束。比较的路径顺序从这些快照与边取得，见[比较指令处理](../NodeInference/比较指令处理.md)。
