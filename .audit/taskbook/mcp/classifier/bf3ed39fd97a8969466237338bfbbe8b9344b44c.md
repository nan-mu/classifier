## 上游原生复现

在未修改的 HEIMDALL `90b4605e1c6ddae7ae5ead9738d5c1ff8e2843ad`，按论文 §3.2、§3.3 和附录 B/C 核对路径生成与等价检查。Darwin arm64，Python 3.12.14，angr/claripy/CLE/pyvex 9.2.176，Z3 Python 4.13.0。在上游 `c2rust_translation` 中运行以下命令。[上游代码](https://github.com/vdasu/heimdall/tree/90b4605e1c6ddae7ae5ead9738d5c1ff8e2843ad) · [论文](https://arxiv.org/html/2605.25411v1#S3.SS2)

```sh
PYTHONPATH=../angr_ebpf_backend python verify_mixed_entries.py \
  c_bpf_programs/KEN/dataset/libbpf/kfree_skb.bpf.o \
  verified_translations/ken_libbpf__kfree_skb/ken_libbpf__kfree_skb.o \
  kfree_skb kfree_skb kfree_skb_total:hash
```

C/Rust 入口分别为 `0x400000` 和 `0x400260`，使用 64 字节 tracepoint context 和 BTF 的 `kfree_skb_total`，初态调用深度 1，EXIT sentinel 为 `0x100100`。SimulationManager 每端产生 15 个 deadended、0 个 errored。上游将 15/15 个守卫结果转换给 Z3，比对返回值和一个 HASH map，三项差异条件均无见证，返回 `equivalent: True`。额外调用原生 `generate_formula_for_program` 保存 C 端 15 条路径的守卫析取，独立 Z3 读回为 SAT。

原生入口使用 CLE 的隐式 ELF 选择。显式构造上游 ExtendedBPF 时，`arch_from_id("bpf")` 在同一环境报 `ArchNotFound`。本轮明确使用该 backend 和上游的小端架构类。XDP 适配及指令边界见 [工具文档](../../../../tooling/angr/README.md)。

## 本轮发布验收

按 [复跑命令](../../../../tooling/angr/README.md#复跑-v011) 执行 `make_specs.py`、`analyze.py release --tag v0.1.1` 和 `acceptance_objects.py --z3 z3`。环境为 Python 3.12.14、angr/claripy 9.2.176、Z3 Python 4.13.0、独立 Z3 5.1.0 和 7-Zip 17.05。12 个对象均为 `analyzed`，23/23 个向量通过。

| 对象 | 向量 | 代表性路径与观察 |
| --- | ---: | --- |
| bsort | 2/2 | 合法请求 132 个回边，比较完整包和 scratch。 |
| case_mark | 2/2 | 长度/偏移 74 的符号用例有三个退出。TX 在偏移 77 写 1，其余 PASS。 |
| case_swap | 2/2 | 同一声明域有三个退出。TX 在偏移 77 写 2，其余 PASS。 |
| copy | 2/2 | 合法请求 155,913 条指令、8,193 个回边和 8,232 次包写入。 |
| firewall | 2/2 | 存在位和旧值均可符号化。命中 DROP 并加一，未命中 PASS。另验 IPv4 源地址一字节可变。 |
| fletcher32 | 2/2 | 合法和短请求的动作及完整有效包一致。 |
| just_drop | 1/1 | 声明的符号包域有一个 DROP 退出。 |
| just_tx | 2/2 | 短包 PASS，合法帧用键 17 更新 rxcnt、交换 MAC 并 TX。初值为 u32 最大值的向量回绕为零。 |
| log2 | 2/2 | 合法请求 9 个回边，比较完整包。短请求在 7 条指令后退出。 |
| noop | 2/2 | 合法和短请求的动作及完整有效包一致。 |
| prime | 2/2 | 合法和短请求的动作及完整有效包一致。 |
| strcmp | 2/2 | 合法和短请求的动作及完整有效包一致。 |

- 六个正向符号用例成立。case_mark、case_swap 的错误版本分别观察到偏移 77 的 1 和 2，firewall 错误计数观察到 1、期望 0。三个见证均通过同一单对象 CLI 复放。
- copy 零回边预算得到 `undetermined`、`loop_budget`、`uncovered` SAT 与 `reachable_gaps` SAT，保留输入域和见证。没有 mode 的单项发布可执行。错误归档摘要、损坏归档、截短 ELF、失效 map 符号和保留字段错误均诊断。
- 独立 Z3 复算 287 份 SMT-LIB。发布为 67 SAT、157 UNSAT，诊断和复放为 22 SAT、41 UNSAT。返回关系、正常退出覆盖、重叠、可达缺口、规格覆盖和否定规格均纳入复算。
- 有效范围和事件由真实 ELF 回归、发布向量共同验证。firewall 的槽 14 查找键 `c0000211`，槽 20 经值指针写 4 字节的 8。just_tx 的槽 64 查找键 `11000000`，槽 70 写 4 字节的 0。分析的 helper 和访存范围限于工具文档所列 XDP 模型。
